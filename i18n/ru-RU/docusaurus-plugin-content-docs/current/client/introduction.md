# Настольный клиент

Powerduck, включая настольное приложение, требует входа через Google OAuth или GitHub. Файлы остаются на диске. Для анализа ИИ выбранный контекст передаётся провайдерам, которыми управляет Powerduck. Собственные адреса моделей и ключи API больше не поддерживаются.

Управление остаётся у вас: ассистент предлагает, вы подтверждаете.

## День в рабочей области

Клиент построен вокруг следующих задач.

- **Открыть спецификацию и разобраться в ней.** Ассистент читает текущий документ и сразу предлагает, что можно сделать: заполнить пробелы, дополнить документацию или проверить процессы.
- **Создать API.** Опишите ресурс, и ассистент предложит конечные точки. Уточняйте ту же операцию: добавляйте параметр, корректируйте ответ или код состояния, не затрагивая посторонние части документа.
- **Подготовить тестовые данные.** Создавайте реалистичные строки примеров из схем, чтобы запросы и сценарии работали с конкретными значениями.
- **Выполнить запрос или целый сценарий.** Отлаживайте один вызов либо объединяйте несколько конечных точек в сквозной процесс и получайте отчёт об успешных и неудачных шагах.
- **Продолжать работу до готовности бэкенда.** Запустите локальный mock, который отвечает по контракту, пока настоящий сервис ещё разрабатывается.
- **Передать API агентам программирования.** Превратите спецификацию в MCP-сервер, чтобы ИИ-инструменты находили и вызывали нужные операции с подходящими аргументами.
- **Увидеть базу данных за API.** Выведите таблицы, связи и SQL из спецификации, сравните их с реальной базой и определите необходимые изменения.
- **Менять настройки прямо в чате.** Попросите сменить тему или язык, настроить прокси либо управлять переменными окружения.

## Как ассистент работает с вами

Вы описываете намерение естественным языком. Ассистент выбирает подходящую функцию, детерминированный движок проверяет её, а вы подтверждаете действие в карточке. Модель никогда не редактирует документ самостоятельно.

- Изменения спецификации приходят в виде **карточек правок** с точечными операциями; при редактировании существующей операции меняется только запрошенное поле;
- Действия только для чтения — список операций, получение схемы, выполнение запроса на чтение — возвращают факты, на которых ассистент строит ответ;
- Действия записи требуют подтверждения перед выполнением.
