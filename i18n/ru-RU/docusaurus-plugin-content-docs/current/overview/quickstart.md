# Первый локальный запрос — без аккаунта и модели ИИ

## Запустите локальный пример

В пустом рабочем пространстве настольного приложения выберите **Попробовать пример** и запустите выполнение. Powerduck создаст отдельный пример, запустит локальный Mock-сервер, отправит `GET /orders/summary` на назначенный порт и покажет реальный ответ. Пример считается выполненным только после ответа HTTP 200. Mock-сервер останавливается после запроса или при закрытии примера. Пример можно запускать повторно. Сначала установите приложение: для этого локального сценария не нужны интернет, вход в аккаунт или ключ модели ИИ.

## Откройте свою спецификацию

Нажмите **Открыть**, чтобы импортировать документ OpenAPI в формате YAML или JSON. Пример не перезаписывает существующие файлы. В бесплатной версии ограничено количество спецификаций. Если лимит достигнут, сохраните, а затем закройте или удалите из рабочего пространства ненужный документ. Не теряйте несохранённые изменения ради запуска примера. Для существующего проекта можно также сгенерировать OpenAPI из кода. Прежде чем полагаться на результат, проверьте поля, в которых нет уверенности.

## Проверьте реальный сервер

Успешный запрос к Mock-серверу ещё не подтверждает соответствие реального сервера спецификации. Выполните [пример с ошибкой контракта](/docs/ru-RU/client/contract-example/), а при необходимости [подключите помощника для программирования](/docs/ru-RU/client/coding-agent/). Для ручной проверки модель ИИ не нужна.

## Необязательные модели и типичные ошибки

- **Модель не настроена:** локальные запросы, Mock-сервер и ручные проверки работают и без неё. Настраивайте модель только для использования ИИ.
- **Не удалось подключиться к модели:** проверьте адрес сервиса, ключ и прокси в настройках. Не публикуйте ключи или заголовки запросов в отчётах об ошибках.
- **Целевой API недоступен:** убедитесь, что сервер запущен, и проверьте URL, порт и параметры запроса в отладчике.
- **HTTP 401/403:** проверьте аутентификацию и права доступа к целевому API. Это не требование войти в Powerduck.
- **Проверка контракта не пройдена:** посмотрите путь к полю и ожидаемый тип в проверочном условии. Исправьте сервер или ошибку в спецификации и повторите проверку.

Локальные файлы читаются и сохраняются на вашем компьютере. Удалённым моделям передаётся необходимый контекст; при публикации в облаке загружается выбранное содержимое. Необязательная статистика использования по умолчанию отключена в настройках и не связана с проверкой лицензии.
