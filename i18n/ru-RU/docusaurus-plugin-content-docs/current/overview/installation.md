# Установка и начало работы

Скачайте с официального сайта macOS Apple Silicon/Intel, Windows или Linux AppImage. Проверяйте источник и издателя, не отключая защиту. Войдите на сайте и вернитесь в приложение; импортируйте API или выберите проект. Браузер показывает API-процессы; локальные файлы и команды требуют настольного приложения.

[Powerduck](https://www.powerduck.com/download.html)

## Встроенный ИИ и использование

Вход через Google или GitHub, только встроенная модель без выбора, собственных ключей и адресов. Запрошенная работа ИИ передаёт выбранный контекст управляемым поставщикам. Исключение обычных зависимостей, сборок и учётных файлов не гарантирует отсутствия секретов в исходниках.

## Тарифы и задачи

Новые тарифы, диалоги/ревью: Free 10/2; Starter $19/месяц 300/20; Pro $39/месяц 700/60; Max $99/месяц 2 000/180. Free обновляется в начале месяца UTC, платные — по расчётному периоду подписки. Остатки не переносятся. Итог и налоги указаны при оплате.

## macOS · Windows · Linux

macOS 11+ · Windows 10+ · Linux · Electron 37

- macOS: `.dmg` · `arm64` / `x64`
- Windows: NSIS `.exe` · SmartScreen
- Linux: `.AppImage` · `x64`

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```
