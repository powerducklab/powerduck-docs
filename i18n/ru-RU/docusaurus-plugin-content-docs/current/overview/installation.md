# Установка

Powerduck — настольное приложение, ориентированное на локальную работу. Оно устанавливается как обычная программа, открывает настоящие файлы на диске и не требует учётной записи для начала работы.

## Загрузка

Загрузите установщик для своей платформы с [сайта Powerduck](https://www.powerduck.com/#download). Следующие сборки создаются с помощью `electron-builder`:

| Платформа | Установщик | Архитектура |
|---|---|---|
| macOS | `.dmg` и `.zip` для автоматического обновления | Apple Silicon (`arm64`) и Intel (`x64`) |
| Windows | Установщик NSIS (`.exe`) | `x64` |
| Linux | AppImage (`.AppImage`) | `x64` |

## macOS

1. Откройте `.dmg` и перетащите Powerduck в папку **Программы**.
2. При первом запуске macOS может запросить подтверждение открытия приложения, загруженного не из App Store. Сначала убедитесь, что оно получено с официальной страницы загрузки; не отключайте системные проверки безопасности.
3. Доступны две сборки: `arm64` для Apple Silicon (серия M) и `x64` для Mac на Intel. Выберите сборку для своего компьютера.

## Windows

1. Запустите установщик NSIS (`.exe`) и следуйте его инструкциям.
2. Если SmartScreen сообщает о неизвестном издателе, сначала убедитесь, что установщик получен с официальной страницы. Продолжайте только после проверки источника; не обходите предупреждение для ненадёжной загрузки.

## Linux

1. Загрузите файл `.AppImage`.
2. Разрешите его выполнение и запустите:

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```

AppImage работает без общесистемной установки. В некоторых дистрибутивах для монтирования файла может потребоваться FUSE.

## Что работает на вашем компьютере

Настольный клиент — приложение Electron, состоящее из двух частей:

- **Главный процесс** (Node.js) управляет доступом к файлам, исходящими HTTP-запросами, локальным mock-сервером, подключениями к базам данных и встроенным терминалом;
- **Процесс отображения** (рабочая область React) показывает спецификацию, чат с ИИ и все инструменты.

В настольном клиенте запросы к ИИ отправляются через главный процесс, поэтому ограничения CORS между браузером и провайдером не применяются. Промпты, соответствующий контекст и учётные данные всё равно отправляются на настроенную конечную точку модели; работа с облачной моделью не является автономной. Разделение процессов не гарантирует, что секреты никогда не попадут в журналы или инструменты разработчика. См. [ИИ и модели](../client/ai-models.md).

## Системные требования

- macOS 11 или новее, Windows 10 или новее либо распространённый настольный дистрибутив Linux, совместимый с Electron 37;
- Достаточно места для приложения; открываемые спецификации остаются в исходных расположениях;
- Сеть нужна для отправки запросов, синхронизации источника Git или обращения к облачной модели ИИ; в остальных случаях приложение работает автономно.

## Лицензирование

Оценивать настольный клиент можно без ограничения по времени. Он продаётся по **бессрочной** лицензии с разовой оплатой — без подписки. Ключ выдаётся при покупке и показывается один раз. Облачный хостинг — отдельный сервис по подписке. Различия описаны в разделе [Оплата облака](../cloud/billing.md).
