# Установка

```bash npm2yarn2pnpm
npm install @powerduck/tree
```

## Одноранговые зависимости

```bash
npm install react react-dom react-icons
```

## Импорт CSS

```tsx
import "@powerduck/tree/react/index.css";
```

## Точки входа

| Импорт | Описание |
|--------|-------------|
| `@powerduck/tree` | Основные типы, утилиты и все адаптеры |
| `@powerduck/tree/react` | Компонент Tree для React и хуки |
| `@powerduck/tree/adapters` | Адаптеры OpenAPI, JSON Schema и документации |
| `@powerduck/tree/core` | Только основные типы и утилиты |
