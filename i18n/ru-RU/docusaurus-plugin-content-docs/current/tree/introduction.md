# @powerduck/tree

Расширяемый компонент дерева для навигации по API, просмотра схем и документации. Построен на универсальном ядре с адаптерами для OpenAPI, JSON Schema и пользовательских источников данных.

- **Имя пакета:** `@powerduck/tree`
- **Версия:** <img src="https://img.shields.io/npm/v/@powerduck/tree"/>
- **Лицензия:** MIT

## Возможности

- **Универсальное ядро** — `TreeNode<TMetadata>` работает с любым источником данных
- **Адаптер OpenAPI** — Навигация по тегам с поддержкой вложенных тегов OAS 3.2, `x-tagGroups`, `x-order`, `x-displayName` и `x-internal`
- **Адаптер JSON Schema** — Глубокое раскрытие вложенных свойств, массивов и комбинаторов с метаданными `jsonPath`
- **Адаптер документации** — Дерево документации в стиле Stripe со счётчиками операций
- **React-компонент** — Поиск, раскрытие и сворачивание, клавиатурная навигация, метки методов и пользовательские render props
- **Перетаскивание** — Изменение порядка внутри одного родителя и перемещение в папки других уровней
- **Контекстное меню** — Действия над узлом по правому клику или кнопке дополнительных действий
- **Императивный поиск** — `locateNode(predicate)` находит узел, раскрывает его предков, выбирает узел и прокручивает до него
- **Интеграция JSON Patch** — Обратный вызов `onPatch` передаёт операции RFC 6902
- **Темы через CSS-переменные** — Совместимость с `tokens.css` Powerduck, светлый и тёмный режимы
