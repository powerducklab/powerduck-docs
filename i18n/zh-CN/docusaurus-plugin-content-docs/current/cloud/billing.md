# 账单与授权

Powerduck 出售**两种不同产品，对应两种不同支付模式**。把它们分开，是理解账单最重要的一点。

| | 桌面客户端 | Powerduck Cloud |
|---|---|---|
| 你买什么 | 桌面应用 | 托管服务 |
| 模式 | 一次性购买 | 按月订阅 |
| 有效期 | 永久——永远拥有 | 当前计费周期 |
| 交付为 | **授权码**，仅展示一次 | 会员资格，**无授权码** |
| 可离线工作 | 是 | 否（它是托管服务） |

Cloud 购买从不会产生授权码，桌面购买也不是订阅。

## 桌面永久授权

桌面客户端一次购买、永久拥有，没有续费或计费周期。购买时生成授权码：

- 授权码由加密安全的随机字节构成，格式为 `PDC-XXXX-XXXX-…`，而不是来自自增 ID 或时间戳；
- 原始授权码仅展示**一次**；
- 数据库只存授权码的 **SHA-256 哈希**和最后四个字符，因此无法从数据库反推出原始授权码。

### 授权状态

授权经历四种状态：

| 状态 | 含义 |
|---|---|
| `ISSUED` | 已生成但尚未激活 |
| `ACTIVE` | 已激活、可用 |
| `SUSPENDED` | 暂时不可用；可重新激活 |
| `REVOKED` | 永久撤销；不可重新激活 |

"永久"意味着它不按计划过期，并不意味着授权永远不能被暂停或撤销。

### 激活与审计

激活会校验授权码格式、对其哈希、查找哈希、检查状态，并在事务中绑定授权。激活端点有速率限制，以阻止暴力枚举。

每次授权码状态变化都记录为一个授权事件——创建、激活、暂停、重新激活或撤销——让生命周期保持可审计。

## Cloud 订阅

Cloud 访问遵循对某计划的**有效订阅**，不涉及授权码：

| 计划 | 按月 | 按年计费 |
|---|---|---|
| Free（免费） | $0 | $0 |
| Pro | $19/月 | $15/月 |
| Team | $49/月 | $39/月 |

处于 `ACTIVE` 且在当前周期内的订阅授予该计划的能力。一个短暂的续费宽限期（三天）覆盖续费前后的时间差；超出该窗口，访问解析为免费计划。Cloud 能力从不会参考桌面授权。

### 计划控制什么

计划不是通过在代码库中硬编码计划名称来强制执行的。每个计划有**权益**——布尔功能和数值配额——通过统一的权益服务检查：

| 能力 | Free | Pro | Team |
|---|---|---|---|
| OAS 托管 | 是 | 是 | 是 |
| Git 来源 | 否 | 是 | 是 |
| 文档 | 是 | 是 | 是 |
| MCP | 否 | 是 | 是 |
| 自定义域名 | 否 | 是 | 是 |
| 最大文档数 | 3 | 100 | 1,000 |
| 最大版本数 | 20 | 200 | 1,000 |
| 最大文件大小 | 1 MiB | 10 MiB | 50 MiB |
| 最大暴露操作数 | 10 | 1,000 | 10,000 |
| 最大成员数 | 1 | 1 | 10 |

## 支付服务商

结账按地区路由，让客户看到熟悉的服务商，两个服务商**从不同时出现**：

- **Antom**——中国大陆、香港、澳门、台湾和东南亚；
- **Paddle**——美国、加拿大、欧洲、日本、韩国、澳大利亚、新西兰和英国。

国家根据客户端时区或 `Accept-Language` 头推断；无需外部 GeoIP 数据库。如果无法确定地区，**以 Antom 兜底**。在运营上也可以通过配置强制指定服务商，这样在某一服务商出现故障时能立即切换到备用通道。

支付通过签名的服务商 Webhook 确认（Paddle 和 Antom 各自独立端点），而不是信任浏览器返回页。

## 我该买哪个？

- 想要完整本地工作区、离线工作和永久拥有？一次购买**桌面授权**。
- 想在线发布文档和 MCP 并分享稳定链接？订阅 **Cloud Pro**（多席位选 Team）。
- 很多团队两者都用：在客户端本地设计和测试，然后在 Cloud 上托管已发布的 API。
