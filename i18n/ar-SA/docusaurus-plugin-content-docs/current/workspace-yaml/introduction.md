# @powerduck/workspace-yaml

هيّئ ملفات workspace.yaml وملفات YAML بتنسيق OpenAPI 3.2 بثقة.

بنية من طبقتين:
- **الطبقة الأساسية**: متوافقة مع المتصفح: دوال نقية تنشئ سلاسل نصية لمحتوى YAML دون الوصول إلى نظام الملفات.
- **طبقة الملفات**: تضيف إلى الطبقة الأساسية في Node.js / Electron عمليات كتابة ذرية وقفل الملفات وتوحيد المسارات.

- **اسم الحزمة:** `@powerduck/workspace-yaml`
- **الإصدار:** <img src="https://img.shields.io/npm/v/@powerduck/workspace-yaml"/>
- **الترخيص:** MIT

هذه المكتبة **تهيّئ الملفات فقط**، لحالات إنشاء ملف جديد أو الإنشاء اليدوي. وهي **لا** تعيد تنفيذ قراءة ملفات YAML أو تصحيحها أو تحديثها. لتنفيذ هذه العمليات، استخدم [`@powerduck/conf-patch`](https://www.npmjs.com/package/@powerduck/conf-patch).
