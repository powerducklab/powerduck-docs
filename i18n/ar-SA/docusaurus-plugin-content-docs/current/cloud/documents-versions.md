# المستندات والنسخ

المستند هو التمثيل المستضاف لواجهة واحدة. ينتمي إلى مشروع في المنظمة ويجمع نسخاً عبر الوقت بدل الاستبدال.

## التسلسل الهرمي

```text
Organization -> Project -> Document -> Versions
```

يمكن إنشاء المستند مباشرة تحت المنظمة أو في مشروع وسرده حسب المشروع والمنظمة.

## دورة حياة الحالة

يمر المستند بأربع حالات.

| الحالة | المعنى | الخدمة العامة |
|---|---|---|
| `ACTIVE` | متصل | التوثيق وMCP مقدَّمان (حسب المؤشرات النشطة) |
| `PAUSED` | موقوف مؤقتاً | الخدمات العامة غير متاحة |
| `ARCHIVED` | محفوظ لكن غير حالي | غير مقدَّم |
| `DELETED` | محذوف حذفاً منطقياً | غير مقدَّم |

الانتقالات المسموحة:

```text
pause:    ACTIVE  -> PAUSED
resume:   PAUSED  -> ACTIVE
archive:  ACTIVE / PAUSED -> ARCHIVED
restore:  ARCHIVED -> ACTIVE
delete:   ACTIVE / PAUSED / ARCHIVED -> DELETED
```

الإيقاف المؤقت أسرع طريق للإنزال والاستئناف؛ الأرشفة تحفظ السجل لكن لا تعامل المستند كحالي؛ الحذف منطقي، لذا لا تُتلف البيانات الأساسية فوراً.

## النسخ غير قابلة للتغيير

عند تغيّر المواصفة، تُضاف نسخة جديدة؛ لا يُستبدَل الأصل أبداً.

```text
v1 -> v2 -> v3 -> v4
```

تسجّل كل نسخة:

- **مفتاح التخزين** للملف في مخزن الكائنات.
- قيمة **SHA-256**.
- نوع المحتوى والحجم ووقت الإنشاء.

هذا يدعم السجل والتراجع والمقارنة وإعادة توليد التوثيق/MCP لنسخة محددة.

### روابط حالية مقابل مثبَّتة على نسخة

- روابط المستند **الحالي** تتبع أحدث نسخة.
- الروابط **المثبَّتة على نسخة** تشير إلى نسخة محددة ولا تتغيّر تحت القارئ.

استخدم الروابط المثبَّتة عندما تتطلب ملاحظات الإصدار أو العقود مرجعاً ثابتاً، والروابط الحالية عندما يلزم الأحدث دائماً.

## المصادر

يأتي المحتوى من مصدر، مُجرَّد كي لا يُربَط الرفع وGit بنموذج المستند.

- **رفع** — إضافة ملف مباشرة.
- **Git** — ربط مستودع عبر الرابط والفرع ومسار الملف.

تتتبّع مصادر Git تفعيل المزامنة وآخر مزامنة.

- **ربط** برابط المستودع ومسار الملف (اختيار الفرع).
- **مزامنة** عند الطلب لجلب أحدث محتوى كنسخة جديدة.

تبقى بيانات تعريف المصدر مع المستند، لمعرفة ما إذا كان من رفع أو مستودع ورؤية آخر مزامنة.

## التخزين

تعيش الملفات الفعلية بترتيب منظمة/مستند/نسخة في مخزن الكائنات، وتحفظ قاعدة البيانات بيانات التعريف فقط (مفتاح التخزين وقيمة التحقق ونوع المحتوى والحجم). الملفات غير قابلة للقراءة العامة افتراضياً في المخزن؛ الوصول العام يمر عبر مسارات المستند المنشورة.

## لماذا يهم

تتيح تركيبة النسخ غير القابلة للتغيير ودورة الحياة ذات الحذف المنطقي التكرار السريع دون فقد السجل، وعدم كشف مستند يجب إيقافه سهواً. إيقاف مؤقت لانقطاع وقتٍ، أرشفة للحفظ طويل المدى، روابط مثبَّتة عندما تهم الثباتية.
