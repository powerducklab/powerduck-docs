# @powerduck/schema-editor

Editor Monaco dengan dukungan skema untuk JSON, YAML, dan JavaScript. Menggunakan JSON Schema apa pun untuk menyediakan saran sebaris, pelengkapan pop-up, daftar nilai enum, pengisian contoh otomatis, dan diagnostik skema.

- **Nama paket:** `@powerduck/schema-editor`
- **Versi:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Lisensi:** MIT

## Fitur

- **Tiga bahasa** — JSON, YAML, dan JavaScript (skrip pengujian Postman)
- **Pelengkapan berbasis skema** — Daftar nilai enum, nama properti, dan pengisian contoh otomatis dari JSON Schema apa pun
- **Teks bayangan** — Saran sebaris untuk token berikutnya yang diharapkan
- **Diagnostik skema** — Kesalahan validasi ditampilkan sebaris, disertai bilah status
- **Berbasis Monaco** — Penyorotan sintaks, minimap, dan palet perintah tersedia di semua editor
- **Tema terang dan gelap** — `powerduck-light` / `powerduck-dark`
- **Modul inti mandiri** — Resolusi skema, pembuatan contoh, dan diagnostik berjalan tanpa React
