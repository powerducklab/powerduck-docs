# إنشاء OpenAPI من مشروع برمجي قائم

في تطبيق سطح المكتب، اختر **مسح الشيفرة لإنشاء OpenAPI** (تجريبي)، وحدد مجلد مصدر محليًا، ثم اختر **بدء المسح**. ابدأ بخدمة صغيرة. راجع المسارات والمعاملات والاستجابات المكتشفة قبل اعتماد المواصفات الناتجة.

قد يترك المسح الثابت مخططات الاستجابة غير معروفة إذا اعتمدت المعالجات على شيفرة ديناميكية أو تبعيات غير متاحة. يسجل «التأكيد اليدوي» مراجعتك، لكنه لا يعيد بناء الأنواع المفقودة. عدّل عقد API استنادًا إلى أدلة، أو اطلب اختياريًا من الذكاء الاصطناعي مراجعة المعالج المحدد. يرسل هذا الإجراء المصدر المحدد وسياقه إلى مزود النموذج المضبوط.

احفظ النتيجة في ملف جديد. لا تستبدل عقدًا قائمًا دون مراجعة التغييرات. بعد ذلك، شغّل [مثال العقد](/docs/ar-SA/client/contract-example/) على خادم خلفي يعمل، أو صِل [وكيل برمجة](/docs/ar-SA/client/coding-agent/). نجاح المسح لا يثبت توافق التنفيذ مع العقد.

هذا المسار متاح على سطح المكتب فقط، ويختلف دعم اللغات وأطر العمل باختلاف الماسح. لا يتطلب المسح الثابت مفتاح نموذج. تعامل مع النتائج غير المحسومة على أنها مجهولة، لا حقائق مستنتجة.
