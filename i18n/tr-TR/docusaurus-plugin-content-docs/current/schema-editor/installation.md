# Kurulum

```bash npm2yarn2pnpm
npm install @powerduck/schema-editor
```

## Eş bağımlılıklar

```bash
npm install react react-dom monaco-editor @monaco-editor/react
```

## Giriş noktaları

| İçe aktarma yolu | Açıklama |
|--------|-------------|
| `@powerduck/schema-editor` | Temel API: şema çözümleme, tanılama ve örnek oluşturma |
| `@powerduck/schema-editor/react` | React `<SchemaEditor />` bileşeni |
| `@powerduck/schema-editor/core` | React gerektirmeyen, tarayıcıda kullanılabilen çekirdek |
