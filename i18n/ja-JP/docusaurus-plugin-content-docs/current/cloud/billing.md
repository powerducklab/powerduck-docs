# プランとタスク回数

新プランは対話／レビューを別々に計数します。Free 20／5 回、Starter $19／月 300／30 回、Pro $39／月 700／90 回、Max $99／月 2,000／270 回。Free は UTC 月初、 有料は購読期間でリセットし繰り越しません。税金を含む最終額は決済画面で確認します。

## 内蔵 AI と利用範囲

対話の一往復またはレビュー操作が一タスクです。内部呼び出しは別課金しません。実行中は予約し、結果を配信すると一回を精算します。配信後の中止でも計数し、成功結果がなければ予約を解除します。大きなレビューは分割してください。ローカル閲覧・Git／AST・保存結果は消費しません。旧購読は従来 credits を維持する場合があり、アカウント表示が適用されます。

## 支払いとサブスクリプションの変更

サブスクリプションの購入・変更は組織の所有者と管理者のみ行えます。アップグレードでは日割り料金が直ちに請求され、ダウングレードは支払い済み期間の終了時に適用されます。更新を解約しても支払い済み期間中は利用でき、適用前の解約予約は取り消せます。

決済後は請求の戻りページで注文の確認をお待ちください。確認が遅れた場合は再度支払わず、既存の注文を更新してください。支払いが拒否された場合は同じ決済画面で再試行できます。更新の解約は返金ではありません。返金はサポートへお問い合わせください。
