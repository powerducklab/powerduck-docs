# 데스크톱 클라이언트

데스크톱 클라이언트는 AI 네이티브 워크플로가 당신 자신의 머신에서 일어나는 곳입니다. 저장소에서 `openapi.yaml`을 열고 원하는 결과를 말한 뒤 검토합니다. 스펙 에디터, HTTP 클라이언트, 모킹 도구, 문서 생성기, 테스트 러너 사이를 전환할 필요가 없고 클라우드 계정 없이 시작할 수 있습니다.

항상 당신이 통제합니다. 어시스턴트가 제안하고 당신이 승인합니다.

## 워크스페이스에서의 하루

다음은 바로 클라이언트가 중심에 두는 순간들입니다.

- **스펙을 열고 전체를 파악하기.** 어시스턴트가 현재 문서를 읽고 할 수 있는 일을 즉시 제안합니다——채울 빈칸, 완성할 문서, 테스트할 플로우.
- **API 구축하기.** 리소스를 설명하면 어시스턴트가 작업을 제안합니다. 같은 작업을 계속 refine——매개변수 추가, 응답 조이기, 상태 코드 조정——하면 문서 전체로 흐트러지지 않고 그 API에 머뭅니다.
- **테스트 데이터 준비하기.** 스키마에서 실제 같은 샘플 데이터를 생성해 요청과 시나리오에 구체적 값을 줍니다.
- **단일 요청 또는 완전한 시나리오 실행하기.** 한 번의 호출을 디버깅하거나 여러 작업을 엔드투엔드 플로우로 연결하고 무엇이 통과하고 실패했는지 공유 가능한 보고서를 받습니다.
- **백엔드 준비 전에 계속 진행하기.** 로컬 모크를 시작해 실제 서비스 개발 중에도 계약에 따라 응답합니다.
- **API를 코딩 에이전트에 전달하기.** 스펙을 MCP 서버로 바꿔 AI 도구가 올바른 매개변수로 올바른 작업을 발견하고 호출하게 합니다.
- **API 뒤의 데이터베이스 내다보기.** 스펙에서 테이블, 관계, SQL을 도출하고 실제 데이터베이스와 대조해 일어나려는 변경을 파악합니다.
- **대화를 떠나지 않고 설정 변경하기.** 테마나 언어 전환, 프록시 설정, 환경 변수 관리를 말로 요청하는 것만으로 수행합니다.

## 각 모드와 용도

단일 문서가 모든 모드를 구동하고 컴팩트한 스위처로 오갑니다.

| 모드 | 무엇을 하는가 |
|---|---|
| [**스펙**](/docs/client/design) | 메인 모드: AI 채팅, 문서, 라이브 미리보기 |
| [**요청 워크스페이스**](/docs/client/debug) | 실제 HTTP 요청을 보내고 검사. 탭과 환경 지원 |
| [**시나리오 테스트**](/docs/client/scenario-testing) | 작업을 플로우로 연결하고 실행해 보고서 받기 |
| [**문서**](/docs/client/protocols) | 스펙을 렌더링된 API 문서로 읽기 |
| [**MCP**](/docs/client/protocols) | 스펙에서 도출한 MCP 서버 확인 및 사용 |
| [**모크 서버**](/docs/client/mock-server) | API 개발 중 로컬 모크 실행 |
| [**데이터 모델**](/docs/client/data-model) | 테이블과 관계를 도출하고 데이터베이스와 대조하며 SQL 생성 |
| [**설정**](/docs/client/settings) | 테마, 언어, 프록시, 인증서, 워크스페이스 기본 설정 |

## 어시스턴트와 협업하는 방식

자연어로 의도를 설명하면 어시스턴트가 적절한 능력을 선택하고 결정론적 엔진이 검증하며 당신이 카드로 승인합니다. 모델이 스스로 문서를 편집하지 않습니다.

- 스펙 변경은 세밀한 작업을 담은 **패치 카드**로 도착합니다. 기존 작업 편집 시 요청한 필드만 변경됩니다.
- 읽기 전용 작업——작업 나열, 스키마 가져오기, 쿼리 실행——은 어시스턴트가 답변의 근거로 삼는 사실을 반환합니다.
- 쓰기 작업은 실행 전 확인을 요청합니다.

모델은 **당신이 구성합니다**. 앱을 어떤 OpenAI 호환 제공업체로든 향하게 하고 설정에서 선택합니다. [AI와 모델](/docs/client/ai-models)을 보세요.

## 로컬 우선이 당신에게 의미하는 것

- **당신의 실제 파일.** 디스크의 실제 파일을 열고 편집하며 저장하고 로컬 변경을 추적합니다.
- **CORS 벽 없음.** 요청이 WebView가 아닌 로컬 프로세스로 전송돼 크로스 오리진 제한이 호출을 막지 않습니다.
- **프롬프트와 키 비공개.** 로컬에서 처리되고 브라우저 네트워크 패널에 나타나지 않습니다.
- **오프라인 동작.** 설계, 모킹, 문서는 네트워크 불필요. 실제 요청, Git 동기화, 호스팅 모델만 네트워크가 필요합니다.
- **로컬 실행 환경.** 모크, 시나리오 러너, 데이터베이스 접근, 터미널이 당신의 머신에서 실행됩니다.

## 데스크톱 라이선스

데스크톱 클라이언트는 **한 번 구매, 영구 라이선스**로 판매됩니다. 한 번 사면 영구 소유하고 완전히 오프라인으로 동작하며 계정이 필요 없습니다. 라이선스 키는 구매 시 생성되고 한 번만 표시됩니다. 월간 구독 호스팅 서비스인 Powerduck Cloud와 별개입니다. [Cloud 청구](/docs/cloud/billing)를 보세요.
