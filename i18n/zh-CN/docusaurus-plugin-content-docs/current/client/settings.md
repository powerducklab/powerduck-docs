# 设置

桌面客户端的设置涵盖应用的外观和发起请求的方式。应用级偏好与对 API 文档的更改相互分开，因此切换主题或配置代理从不会改动契约。

## 外观

- **主题**——在浅色与深色之间切换（`theme.get`、`theme.set`）。更改应用于整个应用并被持久化。
- **界面语言**——选择十种语言之一，或自动跟随系统：

| | | |
|---|---|---|
| English (US) | 简体中文 | 繁體中文 |
| 日本語 | 한국어 | Français |
| Deutsch | Español | Português (Brasil) |
| العربية | | |

阿拉伯语从右到左渲染。选择 `auto` 会跟随系统语言。

## 请求行为

这些设置控制从请求工作区和场景发出的对外请求：

- **请求超时**（`requestTimeoutMs`）——请求超时（毫秒）；`0` 表示不限；
- **严格 SSL**（`strictSSL`）——校验 TLS 证书；对自签名或不受信任证书的服务器可关闭它；
- **跟随重定向**（`followRedirects`）和**最大重定向次数**（`maxRedirects`）；
- **HTTP 版本**（`protocolVersion`）——`http1`、`http2` 或 `auto`；
- **禁用 Cookie**（`disableCookies`）——关闭请求的 Cookie 处理。

## 代理

用一种模式（`off`、`system` 或 `custom`）配置对外代理：

- `off`——不使用代理；
- `system`——跟随操作系统的代理；
- `custom`——使用一个代理 URL，可选用户名、密码和绕过列表。

绕过列表接受主机和模式（例如 `localhost,127.0.0.1` 和通配主机）。代理密码可以写入但从不会被读回；写入空值会清除它。

## TLS 与客户端证书

对于需要自定义信任或双向 TLS 的环境：

- **自定义 CA**——启用 CA 证书并提供其路径，让请求信任内部或自签名根证书；
- **客户端证书（mTLS）**——按主机配置证书，可以是证书/密钥对或 PFX 文件，可选密码短语；证书按主机和端口确定作用域。

证书可以添加、按 ID 删除或清空。证书密码短语只写、从不返回。

## 集成终端

应用包含一个底部终端面板：

- `terminal.open` 显示该面板；传入 `{"cwd":"document"}` 可在当前文档所在文件夹打开，宿主会解析为真实绝对路径；
- `terminal.run` 在一张确认卡片之后，输入并运行一条明确的 Shell 命令。

只有当你明确要求时才会运行命令；显示面板不会执行任何内容。

## 文件与 Shell 动作

- `shell.revealFile`——在系统文件管理器中显示当前文档（或给定路径）；
- `shell.openPath`——用默认应用打开文档；
- `shell.openExternal`——在系统浏览器中打开外部第三方页面。

Powerduck 官方页面使用专门的链接工具（`app.officialLink`），它渲染一张对话内卡片，而不是离开应用。

## 客户端代码示例

对于任何操作，助手都可以生成可直接运行的客户端代码（`clientcode.generate`），并在带语言和客户端库切换器的代码卡片中展示。支持的语言包括 C、C#、Go、Java、JavaScript、Node、Kotlin、PHP、Python、Ruby、Rust、shell、Swift 等。代码在卡片中展示，而不是粘贴进对话。

## 通过助手更改设置

应用级请求——切换主题或语言、设置代理、忽略证书错误或更改 HTTP 版本——由设置工具处理，而不是被当作 API 设计问题。设置更改在应用前要求确认。
