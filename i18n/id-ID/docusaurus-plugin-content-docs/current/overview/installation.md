# Pasang dan mulai

Unduh macOS Apple Silicon/Intel, Windows, atau Linux AppImage dari situs resmi. Periksa sumber dan penerbit tanpa mematikan keamanan. Masuk di situs lalu kembali ke app; impor API atau pilih proyek. Browser untuk mencoba API; analisis file dan perintah lokal memerlukan desktop.

[Powerduck](https://www.powerduck.com/download.html)

## AI bawaan dan penggunaan

Masuk melalui Google atau GitHub. Hanya model bawaan, tanpa pemilih, kunci sendiri, atau endpoint khusus. Pekerjaan AI yang diminta mengirim konteks pilihan ke penyedia terkelola. Pengecualian folder dependensi, build, dan kredensial umum tidak menjamin sumber bebas rahasia.

## Paket dan jumlah tugas

Paket baru menghitung percakapan/tinjauan: Free 10/2; Starter $19/bulan 300/20; Pro $39/bulan 700/60; Max $99/bulan 2.000/180. Free direset awal bulan UTC, paket berbayar mengikuti periode tagihan. Tidak diakumulasi. Harga akhir dan pajak di checkout.

## macOS · Windows · Linux

macOS 11+ · Windows 10+ · Linux · Electron 37

- macOS: `.dmg` · `arm64` / `x64`
- Windows: NSIS `.exe` · SmartScreen
- Linux: `.AppImage` · `x64`

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```
