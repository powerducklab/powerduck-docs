# Подключение OpenAPI к агенту программирования

Используйте **MCP для разработчиков**, чтобы агент программирования мог изучить контракт и проверить бэкенд. **API-to-MCP** предоставляет операции API в виде вызываемых инструментов — это другой сценарий работы.

1. Откройте файл YAML/JSON кнопкой **Открыть** в настольном приложении. Перед экспериментами сохраните отдельную копию.
2. Откройте раздел **MCP и программирование** для текущей спецификации. Также можно выполнить `npm ci` и `npm run build` в локальной копии репозитория MCP для разработчиков.
3. Настройте в агенте MCP-сервер с транспортом stdio: исполняемый файл — `node`, аргументы — `/absolute/path/dev-mcp-server/dist/cli.mjs`, `--spec`, `/absolute/path/openapi.yaml`. Укажите реальные абсолютные пути, не копируйте заполнители буквально.
4. Попросите агента изучить операцию и схему её ответа до изменения бэкенда. После изменения попросите вызвать `run_contract_tests`, явно указав локальный `baseUrl` бэкенда.
5. Проверьте результаты утверждений и предложенный патч кода. Применив одобренное исправление, запустите тесты повторно.

MCP-серверу для разработчиков требуется Node.js 22.12.0 или новее. Агент может отправлять результаты инструментов или контекст кода настроенной удалённой модели. Для ручных локальных запросов и контрактных тестов модель не нужна. Использование вашего ключа оплачивается у вашего провайдера; кредиты размещённых моделей учитываются отдельно. Для локальной работы подписка Cloud не требуется.
