# 기존 코드베이스에서 OpenAPI 생성하기

데스크톱 앱에서 **코드를 스캔하여 OpenAPI 생성**(베타)을 선택하고 로컬 소스 폴더를 지정한 다음 **스캔 시작**을 누르세요. 먼저 작은 서비스로 시작하세요. 생성된 명세를 사용하기 전에 감지된 라우트, 매개변수 및 응답을 검토하세요.

핸들러가 동적 코드나 사용할 수 없는 의존성에 의존하면 정적 스캔으로 응답 스키마를 알아내지 못할 수 있습니다. ‘수동 확인’은 검토 사실을 기록할 뿐, 누락된 타입을 복원하지 않습니다. 확인 가능한 근거로 API 계약을 편집하거나 필요하면 AI에 선택한 핸들러를 검토하도록 요청하세요. 이 AI 작업은 선택한 소스와 컨텍스트를 설정된 모델 제공업체로 전송합니다.

결과를 새 파일로 저장하세요. 변경 사항을 검토하지 않고 기존 계약을 덮어쓰지 마세요. 그런 다음 실행 중인 백엔드에서 [계약 예제](/docs/ko-KR/client/contract-example/)를 실행하거나 [코딩 에이전트](/docs/ko-KR/client/coding-agent/)를 연결하세요. 스캔이 성공했다고 구현이 계약을 준수하는 것은 아닙니다.

이 워크플로는 데스크톱에서만 지원되며 스캐너의 언어 및 프레임워크 지원 범위는 다를 수 있습니다. 정적 스캔에는 모델 키가 필요하지 않습니다. 해결되지 않은 결과는 추론된 사실이 아니라 알 수 없는 항목으로 취급하세요.
