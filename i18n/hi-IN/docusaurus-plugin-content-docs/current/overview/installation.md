# इंस्टॉल करें और शुरू करें

आधिकारिक साइट से macOS Apple Silicon/Intel, Windows या Linux AppImage लें। स्रोत और प्रकाशक जाँचें, सुरक्षा बंद न करें। वेबसाइट पर लॉगिन करके ऐप में लौटें, API या कोड प्रोजेक्ट चुनें। ब्राउज़र API अनुभव के लिए है; फ़ाइल विश्लेषण और स्थानीय आदेश डेस्कटॉप माँगते हैं।

[Powerduck](https://www.powerduck.com/download.html)

## अंतर्निहित AI और उपयोग

Google या GitHub से लॉगिन करें। केवल अंतर्निहित मॉडल है; मॉडल चयन, निजी कुंजी या कस्टम endpoint नहीं। माँगे AI कार्य के लिए चुना संदर्भ प्रबंधित प्रदाताओं को जाता है। सामान्य dependency, build और credential पथ हटाने पर भी स्रोत में रहस्य न होने की गारंटी नहीं है।

## macOS · Windows · Linux

macOS 11+ · Windows 10+ · Linux · Electron 37

- macOS: `.dmg` · `arm64` / `x64`
- Windows: NSIS `.exe` · SmartScreen
- Linux: `.AppImage` · `x64`

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```
