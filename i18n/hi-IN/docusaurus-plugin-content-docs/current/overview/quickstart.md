# Powerduck · Quickstart

डेस्कटॉप सहित Powerduck के उपयोग के लिए Google OAuth या GitHub से लॉगिन आवश्यक है। फ़ाइलें स्थानीय डिस्क पर रहती हैं। AI विश्लेषण चुना हुआ संदर्भ Powerduck द्वारा प्रबंधित प्रदाताओं को भेजता है। अपने मॉडल URL और API कुंजियाँ अब समर्थित नहीं हैं।

Free में प्रतिदिन 300,000 credits मिलते हैं और UTC 00:00 पर रीसेट होते हैं। Pro: $39/माह और हर 7 दिन 18,000,000 credits। Max: $99/माह और हर 7 दिन 60,000,000 credits। चक्र पहली सदस्यता के आरंभ से चलता है, मासिक बिल से अलग। बचा हुआ शेष आगे नहीं जुड़ता। डेस्कटॉप और AI Chat व्यक्तिगत योजना साझा करते हैं; स्थायी लाइसेंस और सक्रियण कुंजियाँ अब नहीं बिकतीं।
