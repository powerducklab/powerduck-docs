# Instalación

```bash npm2yarn2pnpm
npm install @powerduck/tree
```

## Dependencias de pares

```bash
npm install react react-dom react-icons
```

## Importar CSS

```tsx
import "@powerduck/tree/react/index.css";
```

## Puntos de entrada

| Importación | Descripción |
|--------|-------------|
| `@powerduck/tree` | Tipos básicos, utilidades y todos los adaptadores |
| `@powerduck/tree/react` | Componente Tree de React y hooks |
| `@powerduck/tree/adapters` | Adaptadores de OpenAPI, JSON Schema y documentación |
| `@powerduck/tree/core` | Solo tipos básicos y utilidades |
