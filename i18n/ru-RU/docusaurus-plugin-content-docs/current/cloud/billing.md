# Оплата и лицензирование

Powerduck предлагает **два отдельных продукта с разными моделями оплаты**. Для понимания оплаты важно различать их.

| | Настольный клиент | Powerduck Cloud |
|---|---|---|
| Что вы покупаете | Настольное приложение | Облачный сервис |
| Модель | Разовая покупка | Бесплатный план или платная подписка |
| Срок действия | Бессрочно: лицензия остаётся у вас | Бесплатный доступ или оплаченный расчётный период |
| Что предоставляется | **Лицензионный ключ**, показываемый один раз | Возможности плана, **без ключа** |
| Работа без интернета | Да | Нет: это облачный сервис |

Покупка Cloud никогда не создаёт лицензионный ключ, а покупка настольного приложения не является подпиской.

## Бессрочная настольная лицензия

Настольный клиент приобретается один раз и остаётся у вас без продлений и расчётных периодов. При покупке создаётся лицензионный ключ:

- Ключи создаются из криптографически стойких случайных байтов в формате `PDC-XXXX-XXXX-…`, а не из последовательного идентификатора или метки времени;
- Исходный ключ показывается **один раз**;
- База данных хранит только **хеш SHA-256** ключа и его последние четыре символа, поэтому восстановить исходный ключ из базы невозможно.

### Состояние лицензии

У лицензии четыре возможных состояния:

| Состояние | Значение |
|---|---|
| `ISSUED` | Создана, но ещё не активирована |
| `ACTIVE` | Активирована и доступна для использования |
| `SUSPENDED` | Временно недоступна; может быть восстановлена |
| `REVOKED` | Окончательно отозвана; восстановление невозможно |

«Бессрочная» означает отсутствие установленной даты истечения, а не невозможность приостановки или отзыва лицензии.

### Активация и аудит

При активации проверяется формат ключа, вычисляется и ищется его хеш, проверяется состояние и в рамках транзакции выполняется привязка лицензии. Частота запросов к эндпоинту активации ограничена, чтобы затруднить перебор ключей.

Каждое изменение состояния записывается как событие лицензии: создание, активация, приостановка, восстановление или отзыв. Это позволяет проверить весь жизненный цикл.

## Планы и подписки Cloud

Cloud предлагает **план Free** и платные подписки без лицензионного ключа. Годовые цены ниже приведены в пересчёте на месяц; оплата производится за год:

| План | Ежемесячная оплата | При оплате за год |
|---|---|---|
| Free | $0 | $0 |
| Pro | 19 $/мес. | 15 $/мес. |
| Team | 49 $/мес. | 39 $/мес. |

Подписка `ACTIVE` в пределах текущего периода даёт доступ к возможностям плана. Трёхдневный льготный период покрывает возможные задержки продления; после него применяются права плана Free. Настольные лицензии не участвуют в определении возможностей Cloud.

### Что регулируют планы

Имена планов не зашиты в проверки по всему коду. У каждого плана есть **права использования**: включаемые функции и числовые квоты, которые проверяются единым сервисом:

| Возможность | Free | Pro | Team |
|---|---|---|---|
| Размещение OAS | Да | Да | Да |
| Источник Git | Нет | Да | Да |
| Документация | Да | Да | Да |
| MCP | Да | Да | Да |
| Собственный домен | Нет | Да | Да |
| Максимум документов | 3 | 100 | 1,000 |
| Максимум версий | 20 | 200 | 1,000 |
| Максимальный размер файла | 1 MiB | 10 MiB | 50 MiB |
| Максимум доступных операций | 10 | 1,000 | 10,000 |
| Максимум участников | 1 | 1 | 10 |

## Платёжные провайдеры

Провайдер оплаты выбирается по региону, чтобы предложить привычный способ оплаты. Два провайдера **никогда не показываются одновременно**:

- **Antom**: материковый Китай, Гонконг, Макао, Тайвань и Юго-Восточная Азия;
- **Paddle**: США, Канада, Европа, Япония, Корея, Австралия, Новая Зеландия и Великобритания.

Страна определяется по часовому поясу клиента или заголовку `Accept-Language`; внешняя база GeoIP не нужна. Если регион определить не удалось, **используется Antom**. Провайдера также можно принудительно выбрать в конфигурации, чтобы при сбое быстро переключиться на резервный канал.

Оплата подтверждается подписанными вебхуками провайдеров с отдельными эндпоинтами для Paddle и Antom; возврат браузера на страницу сайта сам по себе не считается подтверждением.

## Что выбрать?

- Нужны полноценная локальная работа, автономный режим и бессрочное владение? Приобретите **настольную лицензию** один раз.
- Хотите публиковать документацию и MCP в интернете и делиться постоянными ссылками? Начните с **Cloud Free**. Выберите **Pro** для увеличенных квот, источников Git и собственных доменов или **Team** для нескольких участников.
- Многие команды используют оба продукта: проектируют и тестируют локально в клиенте, затем размещают опубликованную API в Cloud.
