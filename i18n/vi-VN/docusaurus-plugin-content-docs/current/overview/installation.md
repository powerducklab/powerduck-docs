# Cài đặt và bắt đầu

Tải macOS Apple Silicon/Intel, Windows hoặc Linux AppImage từ trang chính thức. Kiểm tra nguồn và nhà phát hành, không tắt bảo vệ. Đăng nhập trên web rồi quay lại app; nhập API hoặc chọn mã. Trình duyệt để trải nghiệm API; phân tích tệp và lệnh cục bộ cần desktop.

[Powerduck](https://www.powerduck.com/download.html)

## AI tích hợp và sử dụng

Đăng nhập Google hoặc GitHub. Chỉ có mô hình tích hợp, không chọn mô hình, khóa riêng hay endpoint tùy chỉnh. Công việc AI được yêu cầu gửi ngữ cảnh chọn tới nhà cung cấp quản lý. Loại trừ thư mục phụ thuộc, build và thông tin đăng nhập phổ biến không bảo đảm mã không có bí mật.

## Gói và số tác vụ

Gói mới tính hội thoại/rà soát: Free 10/2; Starter $19/tháng 300/20; Pro $39/tháng 700/60; Max $99/tháng 2.000/180. Free đặt lại đầu tháng UTC, gói trả phí theo kỳ thuê bao. Không cộng dồn. Giá cuối và thuế tại thanh toán.

## macOS · Windows · Linux

macOS 11+ · Windows 10+ · Linux · Electron 37

- macOS: `.dmg` · `arm64` / `x64`
- Windows: NSIS `.exe` · SmartScreen
- Linux: `.AppImage` · `x64`

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```
