# @powerduck/schema-editor

Редактор Monaco с поддержкой схем для JSON, YAML и JavaScript. Работает с любой JSON Schema и предлагает встроенные подсказки, всплывающее автодополнение, списки значений перечислений, автозаполнение примеров и диагностику схемы.

- **Имя пакета:** `@powerduck/schema-editor`
- **Версия:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Лицензия:** MIT

## Возможности

- **Три языка** — JSON, YAML и JavaScript (тестовые скрипты Postman)
- **Автодополнение на основе схемы** — Списки значений перечислений, имена свойств и автозаполнение примеров из любой JSON Schema
- **Призрачный текст** — Подсказки следующего ожидаемого токена прямо в строке
- **Диагностика схемы** — Ошибки проверки прямо в тексте и строка состояния
- **На основе Monaco** — Подсветка синтаксиса, мини-карта и палитра команд во всех редакторах
- **Светлая и тёмная темы** — `powerduck-light` / `powerduck-dark`
- **Независимое ядро** — Разрешение схем, генерация примеров и диагностика работают без React
