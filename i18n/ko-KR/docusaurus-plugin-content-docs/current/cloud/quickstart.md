# Cloud 빠른 시작

이 경로는 스펙을 당신 머신에서 공유 가능한 문서 페이지와 MCP 엔드포인트로 운반합니다.

## 1. 로그인

로그인 페이지에서 **Google** 또는 **GitHub**로 계속합니다. OAuth 핸드셰이크 후 Powerduck이 자체 세션을 만들고 콘솔로 안내합니다. 개인 조직이 자동 생성됩니다.

## 2. 스펙 추가

대시보드에서 지원 소스 중 하나로 스펙을 추가합니다.

- **파일 업로드**——OpenAPI 파일 직접 업로드.
- **Git 저장소**——저장소를 가리키고 브랜치와 파일 경로 선택.
- **URL**——URL에서 스펙 가져오기.

기존 OpenAPI 3.0/3.1과 Swagger 문서는 업그레이드되고 cURL이나 Postman 입력은 저장 전 변환해 미리볼 수 있습니다.

### 직접 업로드 작동 방식

큰 파일은 API 경유가 아닌 객체 저장소로 직접 업로드됩니다.

1. 문서 생성.
2. 앱이 콘텐츠 유형과 크기로 **업로드 URL** 요청.
3. 파일이 사전 서명 URL로 저장소에 직접 업로드.
4. 업로드를 **완료**하고 버전과 SHA-256 기록.

이로써 API 서버가 큰 페이로드 데이터 경로에 들어가지 않습니다.

## 3. 노출 작업 선택

스펙이 갖춰지면 어떤 작업을 공개할지 선택합니다. 개별로 전환 가능하고 원본 문서는 바뀌지 않습니다. 모두 활성으로 시작해 내부/관리 인터페이스를 좁힐 수 있습니다.

## 4. 링크 열기

문서가 활성이 되면 문서 워크스페이스가 공개 주소를 표시합니다.

- **Documentation**——공개 뷰어의 렌더링 API 문서.
- **MCP**——관리형 Streamable HTTP MCP 엔드포인트.
- 원본 스펙 데이터도 안정 URL로 제공.

기본으로 문서는 활성이고 비밀번호 추가 시에만 보호됩니다. MCP 가용성과 접근 키는 개별 구성됩니다.

## 5. 필요 시 접근 보호

- 문서에 **보기 비밀번호**와 선택적 유효 기간 추가.
- MCP 엔드포인트에 **MCP 접근 키** 생성.
- 문서 일시정지로 둘 다 임시로 내릴 수 있음.

## 6. 버전으로 반복

API가 바뀔 때 이전 버전을 교체하지 않고 새 내용을 새 버전으로 업로드합니다. 공유 링크는 현재 문서를 가리키거나 특정 버전에 고정할 수 있어 어떤 버전을 참조하는 링크가 독자 발 아래서 바뀌지 않습니다.
