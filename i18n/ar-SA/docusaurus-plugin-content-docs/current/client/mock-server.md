# خادم المحاكاة المحلي

يقدّم خادم المحاكاة نسخة فعّالة من واجهتك مباشرة من المواصفة، لتسريع عمل الواجهة الأمامية والعميل قبل جاهزية الخلفية. بلا بنية تحتية خارجية؛ يعمل في العملية الرئيسية لسطح المكتب.

## بدء محاكاة

يمكنك تشغيلها في نمط الخادم أو مباشرة في محادثة الذكاء الاصطناعي؛ ومن المحادثة يؤكّد التطبيق عنوان الخدمة.

الخيارات المتاحة.

| الخيار | النطاق/الشكل | الغرض |
|---|---|---|
| `port` | عدد صحيح `1`–`65535` | المنفذ المحلي للاستماع |
| `basePath` | بادئة مسار URL | التقديم تحت مسار أساسي |
| `latencyMs` | `0`–`10000` | تأخير مصطنع لمحاكاة زمن الشبكة |
| `overrides` | حتى 100 تجاوز | إرجاع رد محدد لعمليات مختارة |

تُرفَض قيم المنفذ أو التأخير غير الصالحة برسالة واضحة دون بدء خادم معطوب.

## محاكيات متعددة

يمكن تشغيل عدة محاكيات بالتوازي — مثلاً واحدة لكل مستند مفتوح. يسرد التطبيق المحاكيات العاملة (`mock:list`) ويمكنه إيقاف كل واحدة (`mock:stop`). كل واحدة مرتبطة بمعرّف واسم مستند.

## فحص الطلبات المستلَمة

تسجّل المحاكاة الطلبات المستلَمة؛ قابلة للاستعلام (`mock:requests`، حد اختياري) ويمكن مسح السجل. يساعد هذا في التحقق من استدعاء العميل للعمليات الصحيحة بالمعاملات المتوقعة، حتى بلا خلفية فعلية.

## تجاوزات الرد

عندما لا تكفي الأمثلة الافتراضية أو الردود المشتقّة من المخطط، تُعيد التجاوزات رداً مختاراً لعمليات محددة. حد أقصى (100) يُبقي الإعداد متوقعاً.

## متى يُستخدم

- إزالة انسداد تطوير الواجهة الأمامية مع عقد قيد الإنشاء.
- محاكاة المواقف البطيئة أو الحالات الحدية عبر التأخير والردود.
- عرض تدفّقات الواجهة دون بيئة منشورة.
- التحقق من استدعاء العميل المولَّد للعمليات كما هو متوقّع.

تقرأ المحاكاة المواصفة نفسها كبقية الأنماط، لذا تبقى متوافقة مع العقد عند تغيّر التصميم.
