# Installation

```bash npm2yarn2pnpm
npm install @powerduck/tree
```

## Dépendances homologues

```bash
npm install react react-dom react-icons
```

## Import du CSS

```tsx
import "@powerduck/tree/react/index.css";
```

## Points d’entrée

| Import | Description |
|--------|-------------|
| `@powerduck/tree` | Types de base, utilitaires et tous les adaptateurs |
| `@powerduck/tree/react` | Composant Tree pour React et hooks |
| `@powerduck/tree/adapters` | Adaptateurs OpenAPI, JSON Schema et documentation |
| `@powerduck/tree/core` | Types de base et utilitaires uniquement |
