# Cài đặt

```bash npm2yarn2pnpm
npm install @powerduck/tree
```

## Phụ thuộc ngang hàng

```bash
npm install react react-dom react-icons
```

## Nhập CSS

```tsx
import "@powerduck/tree/react/index.css";
```

## Điểm vào

| Đường dẫn nhập | Mô tả |
|--------|-------------|
| `@powerduck/tree` | Các kiểu dữ liệu cốt lõi, tiện ích và tất cả bộ điều hợp |
| `@powerduck/tree/react` | Thành phần Tree của React và các hook |
| `@powerduck/tree/adapters` | Bộ điều hợp OpenAPI, JSON Schema và tài liệu |
| `@powerduck/tree/core` | Chỉ gồm các kiểu dữ liệu cốt lõi và tiện ích |
