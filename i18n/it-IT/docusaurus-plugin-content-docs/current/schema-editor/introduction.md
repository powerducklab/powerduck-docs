# @powerduck/schema-editor

Editor Monaco con supporto agli schemi per JSON, YAML e JavaScript. Basato su qualsiasi JSON Schema, offre suggerimenti in linea, completamento a comparsa, menu di valori enumerati, compilazione automatica degli esempi e diagnostica dello schema.

- **Nome del pacchetto:** `@powerduck/schema-editor`
- **Versione:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Licenza:** MIT

## Funzionalità

- **Tre linguaggi** — JSON, YAML e JavaScript (script di test Postman)
- **Completamento basato sullo schema** — Menu di valori enumerati, nomi delle proprietà e compilazione automatica degli esempi da qualsiasi JSON Schema
- **Testo fantasma** — Suggerimenti in linea per il prossimo token previsto
- **Diagnostica dello schema** — Errori di validazione in linea e barra di stato
- **Basato su Monaco** — Evidenziazione della sintassi, minimappa e tavolozza dei comandi in tutti gli editor
- **Temi chiaro e scuro** — `powerduck-light` / `powerduck-dark`
- **Modulo principale autonomo** — Risoluzione degli schemi, generazione degli esempi e diagnostica senza React
