# 套餐与额度

Powerduck 使用账户订阅，桌面端与 AI Chat 共用套餐。软件激活码和一次性模型包不再销售。

| 套餐 | 月费 | 每周期 credits | 重置周期 |
| --- | ---: | ---: | --- |
| Free | $0 | 300,000 | 每日 UTC 00:00 |
| Pro | $39 | 18,000,000 | 每 7 日 |
| Max | $99 | 60,000,000 | 每 7 日 |

付费额度从订阅起点计算，账单周期与额度周期独立。未用完的额度不累计。实际税费与最终付款金额以结账页面为准。

使用 Google 或 GitHub 登录后，从账户菜单进入“管理套餐”，可升级、预约降级、在付费周期结束时取消，或在取消生效前恢复订阅。

AI Chat、代码审查和测试草案使用相同额度。仅查看已有结果和代码差异不会调用模型。模型请求先预占额度，成功后结算，失败或取消则释放。
