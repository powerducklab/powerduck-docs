# Instalar e começar

Baixe do site oficial macOS Apple Silicon/Intel, Windows ou Linux AppImage. Verifique origem e publicador sem desativar a segurança. Entre no site e retorne ao app; importe API ou escolha código. O navegador permite explorar API; análise de arquivos e comandos locais exigem desktop.

[Powerduck](https://www.powerduck.com/download.html)

## IA integrada e uso

Entre com Google ou GitHub. O modelo é integrado, sem seletor, chaves próprias ou endpoints personalizados. Trabalho IA solicitado envia contexto escolhido aos provedores gerenciados. Caminhos comuns de dependências, build e credenciais são excluídos, mas ainda pode haver segredos no código.

## Planos e tarefas

Novos planos contam conversas/revisões: Free 10/2; Starter $19/mês 300/20; Pro $39/mês 700/60; Max $99/mês 2.000/180. Free reinicia no começo do mês UTC; pagos seguem o período da assinatura. Sem acúmulo. Preço final e impostos no checkout.

## macOS · Windows · Linux

macOS 11+ · Windows 10+ · Linux · Electron 37

- macOS: `.dmg` · `arm64` / `x64`
- Windows: NSIS `.exe` · SmartScreen
- Linux: `.AppImage` · `x64`

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```
