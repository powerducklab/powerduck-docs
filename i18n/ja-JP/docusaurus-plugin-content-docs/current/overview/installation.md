# インストール

Powerduck デスクトップクライアントはローカルファーストのアプリです。他のデスクトッププログラムと同じようにインストールされ、ディスク上の実際のファイルを開き、アカウントなしで使い始められます。

## ダウンロード

[Powerduck のウェブサイト](https://www.powerduck.com/#download)からお使いのプラットフォーム向けインストーラーを入手してください。以下のビルドが `electron-builder` で生成されています。

| プラットフォーム | インストーラー | アーキテクチャ |
|---|---|---|
| macOS | `.dmg`（自動更新用の `.zip` も） | Apple Silicon（`arm64`）と Intel（`x64`） |
| Windows | NSIS セットアップ（`.exe`） | `x64` |
| Linux | AppImage（`.AppImage`） | `x64` |

## macOS

1. `.dmg` を開き、Powerduck を**アプリケーション**にドラッグします。
2. 初回起動時、App Store 以外からダウンロードしたアプリを開く確認が表示される場合があります。ダイアログで許可するか、アプリを右クリックして**開く**を選択してください。
3. Apple Silicon（M シリーズ）向けの `arm64` ビルドと、Intel Mac 向けの `x64` ビルドの 2 つが公開されています。お使いのマシンに合うものをダウンロードしてください。

## Windows

1. NSIS インストーラー（`.exe`）を実行し、セットアップ手順に従います。
2. SmartScreen で発行元が認識されない旨が表示された場合は、**詳細情報**を選び、**実行**してください。

## Linux

1. `.AppImage` をダウンロードします。
2. 実行権限を付与して実行します。

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```

AppImage はシステム全体へのインストールなしで動作します。一部のディストリビューションでは、マウントに FUSE のインストールが必要な場合があります。

## マシン上で動作するもの

デスクトップクライアントは 2 つの部分からなる Electron アプリです。

- ファイルアクセス、外部への HTTP リクエスト、ローカルモックサーバー、データベース接続、統合ターミナルを担う**メインプロセス**（Node.js）。
- 仕様、AI チャット、各ツールを描画する**レンダラー**（React ワークスペース）。

この分割はセキュリティと信頼性にとって重要です。ネットワークやファイルシステムへのアクセスが必要なリクエストは WebView ではなくメインプロセスが処理するため、プロンプトと API キーがブラウザのコンソールに現れず、ブラウザからプロバイダーへの直接的な CORS 制限も適用されません。[AI とモデル](../client/ai-models.md)をご覧ください。

## システム要件

- 現在サポートされている macOS、Windows 10 以降、または主要な Linux デスクトップディストリビューション。
- アプリを置く十分なディスク容量。開く仕様は元の場所に残ります。
- リクエストの送信、Git ソースの同期、ホスト型 AI モデルの呼び出し時にのみネットワークが必要で、それ以外ではオフラインで動作します。

## ライセンス

デスクトップクライアントは自由に評価できます。サブスクリプションなしの、買い切りで**永久**ライセンスとして販売されています。ライセンスキーは購入時に生成され、一度だけ表示されます。クラウドホスティングはサブスクリプション型の別のサービスです。違いについては[クラウドの請求](../cloud/billing.md)をご覧ください。
