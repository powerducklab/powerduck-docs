# @powerduck/schema-editor

محرر Monaco يدعم المخططات لتحرير JSON وYAML وJavaScript. يعمل مع أي JSON Schema ويوفر اقتراحات ضمن السطر، وإكمالًا منبثقًا، وقوائم للقيم المعدّدة، وتعبئة تلقائية للأمثلة، وتشخيص المخطط.

- **اسم الحزمة:** `@powerduck/schema-editor`
- **الإصدار:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **الترخيص:** MIT

## الميزات

- **ثلاث لغات** — JSON وYAML وJavaScript (نصوص اختبار Postman)
- **إكمال يستند إلى المخطط** — قوائم للقيم المعدّدة وأسماء الخصائص وتعبئة تلقائية للأمثلة من أي JSON Schema
- **نص اقتراحي** — اقتراحات ضمن السطر للرمز التالي المتوقع
- **تشخيص المخطط** — عرض أخطاء التحقق ضمن السطر مع شريط حالة
- **مبني على Monaco** — تمييز الصياغة وخريطة مصغرة ولوحة أوامر في جميع المحررات
- **سمتان فاتحة وداكنة** — `powerduck-light` / `powerduck-dark`
- **وحدة أساسية مستقلة** — حل المخططات وإنشاء الأمثلة والتشخيص تعمل دون React
