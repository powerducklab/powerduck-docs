# Powerduck Cloud

تحوّل Powerduck Cloud ملف OpenAPI إلى شيء **قابل للمشاركة**. أضف مواصفتك واختر ما تريد عرضه، ثم شارك روابط ثابتة للتوثيق المعروض وخادم MCP مُدار. بلا استضافة ذاتية ولا تشغيل أي شيء.

إنه التدفّق الموجَّه بالعقد والمدفوع بالذكاء الاصطناعي نفسه كعميل سطح المكتب، لكن عبر الإنترنت للفرق والمستهلكين.

## التدفّق

1. **إضافة المواصفة** — ملف أو مستودع Git أو رابط. يمكنك بدء التدفّق من الموقع وتسجيل الدخول عند النشر دون إعادة الرفع.
2. **اختيار العرض.** العمليات مفعَّلة فرادى؛ لا يتغيّر الملف الأصلي.
3. **فتح رابط التوثيق فوراً** — التوثيق مفعَّل افتراضياً. تبقى نقطة MCP معطّلة حتى تريد تقديم أدوات للوكلاء: مفتاح تبديل.
4. **التحكم بالوصول.** إضافة كلمة مرور عرض وتاريخ انتهاء، إضافة مفتاح وصول MCP مستقل للوكلاء.
5. **النشر والمشاركة.** انشر المنتجات النهائية للنسخة الحالية: الروابط تعمل، والتحكم المتقدم على بُعد نقرة.
6. **البقاء محدّثاً.** كل تغيير ينشئ نسخة جديدة للمقارنة/التراجع، وتتزامن مصادر Git مع التحديثات.
7. **إدارة دورة الحياة.** الإيقاف المؤقت والاستئناف والأرشفة ورؤية الحالة والنسخة والمصدر بنظرة.

## ما تحصل عليه

- **رابط توثيق ثابت** — مقروء بعد النسخ الجديدة.
- **نقطة MCP مُدارة** — يكتشف وكلاء الذكاء الخارجيون العمليات المختارة ويستدعونها.
- **عرض لكل عملية** — استبعاد الواجهات الداخلية/غير المكتملة من السطح العام.
- **تحكم بالوصول** — كلمة مرور العرض، الانتهاء، مفتاح وصول MCP.
- **سجل النسخ** — المقارنة والتراجع؛ لا يُستبدَل الأصل أبداً.
- **مزامنة Git** — تعكس تحديثات المستودع كنسخ مستضافة جديدة.
- **نطاقات مخصصة** — تجربة العلامة مع ضبط المسار الفرعي.

### مستند واحد، نسخ متعددة

كل تعديل ينشئ نسخة جديدة بدل الاستبدال، للمقارنة والتراجع وإعادة توليد التوثيق/MCP لحالة محددة. التوثيق وMCP مرتبطان دائماً بمستند ونسخة محددين، لا بـ«الحالة الحالية» المبهمة.

### لماذا قد لا يفتح رابط

يعمل رابط التوثيق أو MCP عند توفر ثلاثة أمور، ويُظهر مساحة المستند كل واحدة ويبرز أول شرط ناقص.

1. المستند **نشط** — الإيقاف المؤقت يُنزِل التوثيق وMCP معاً.
2. النمط المُشارَك **نشط** — مفتاح لكل نمط للتوثيق وMCP (التوثيق مفعَّل افتراضياً، MCP معطّل افتراضياً).
3. المنتج الحالي **منشور** — يُبنى تلقائياً بعد إضافة نسخة أو تغيير العرض، غالباً بلا إجراء؛ نشر يدوي كاحتياط.

تعمل فحوص الوصول — كلمة مرور العرض، الانتهاء، مفتاح وصول MCP — فوق هذه الثلاثة.

## تسجيل الدخول والانتماء

سجّل الدخول بـ**Google** أو **GitHub**. بعد مصافحة OAuth، تُصدِر Powerduck جلستها الخاصة في ملف تعريف ارتباط HttpOnly آمن، ولا يُعَد رمز المزوّد هوية طويلة الأمد. كل شيء ينتمي إلى **منظمة**؛ تُنشَأ منظمة شخصية تلقائياً للمشاركة الجماعية لاحقاً دون إعادة تصميم.

## وحدة التحكم

- **Dashboard** — إضافة المواصفات ورؤية المستندات الأخيرة بروابط سريعة وإجراءات تشغيل/إيقاف.
- **Projects** — تنظيم المستندات.
- **مساحة المستند** — الحالة والتوثيق وMCP والعمليات المعروضة والنسخ والمصدر والنطاقات في تبويبات واضحة.
- **Billing** — حالة الاشتراك والطلبات منفصلة.
- **Hub** — نشر واستكشاف التوثيق وخوادم MCP العامة.
- **Settings** و**Activity** — الملف الشخصي والتفضيلات وسجل التدقيق.

يستخدم القرّاء العامون عارضاً خاصاً ولا يحتاجون حساباً إذا لم يطلب المستند كلمة مرور.

## السحابة مقابل عميل سطح المكتب

| | عميل سطح المكتب | السحابة |
|---|---|---|
| التشغيل | جهازك | مستضاف |
| النموذج | ترخيص دائم، شراء لمرة واحدة | اشتراك شهري |
| النتيجة | مفتاح ترخيص (يظهر مرة) | عضوية بلا مفتاح |
| متى | محلي، دون اتصال، نطاق كامل | المشاركة والنشر عبر الإنترنت |

يكمل أحدهما الآخر ويُباعان منفصلين. انظر [الفوترة](./billing.md).
