# @powerduck/schema-editor

支援結構描述感知的 Monaco 編輯器，適用於 JSON、YAML 與 JavaScript。可由任意 JSON Schema 驅動，提供行內預覽建議、快顯補全、列舉下拉選單、範例自動填入與結構描述診斷。

- **套件名稱:** `@powerduck/schema-editor`
- **版本:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **授權條款:** MIT

## 功能

- **三種語言** — JSON、YAML 與 JavaScript（Postman 測試指令碼）
- **結構描述驅動的補全** — 根據任意 JSON Schema 提供列舉下拉選單、屬性名稱與範例自動填入
- **行內預覽建議** — 以行內方式提示下一個預期的語彙單元
- **結構描述診斷** — 在行內顯示驗證錯誤，並提供狀態列
- **以 Monaco 為基礎** — 所有編輯器皆支援語法醒目提示、縮圖與命令選擇區
- **淺色與深色佈景主題** — `powerduck-light` / `powerduck-dark`
- **獨立核心** — 結構描述解析、範例產生與診斷無需 React 即可運作
