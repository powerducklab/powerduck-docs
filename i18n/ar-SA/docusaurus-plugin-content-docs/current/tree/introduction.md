# @powerduck/tree

مكوّن شجرة قابل للتوسعة للتنقل في API واستكشاف المخططات وعرض التوثيق. مبني على وحدة أساسية عامة مع محولات لـ OpenAPI وJSON Schema ومصادر البيانات المخصصة.

- **اسم الحزمة:** `@powerduck/tree`
- **الإصدار:** <img src="https://img.shields.io/npm/v/@powerduck/tree"/>
- **الترخيص:** MIT

## الميزات

- **وحدة أساسية عامة** — يعمل `TreeNode<TMetadata>` مع أي مصدر بيانات
- **محول OpenAPI** — تنقل قائم على الوسوم مع دعم وسوم OAS 3.2 المتداخلة و`x-tagGroups` و`x-order` و`x-displayName` و`x-internal`
- **محول JSON Schema** — توسيع متعمق للخصائص المتداخلة والمصفوفات وتركيبات المخططات مع بيانات `jsonPath` الوصفية
- **محول التوثيق** — شجرة توثيق بأسلوب Stripe مع شارات لعدد العمليات
- **مكوّن React** — بحث وتوسيع وطي وتنقل بلوحة المفاتيح وشارات للطرق وخصائص عرض مخصصة
- **سحب وإفلات** — إعادة الترتيب تحت الأصل نفسه والنقل إلى مجلدات في مستويات أخرى
- **قائمة سياقية** — إجراءات لكل عقدة بالنقر بزر الفأرة الأيمن أو زر المزيد
- **تحديد الموقع برمجيًا** — تجد `locateNode(predicate)` العقدة وتوسع أسلافها وتحددها وتمررها إلى المنطقة المرئية
- **تكامل JSON Patch** — يرسل رد النداء `onPatch` عمليات RFC 6902
- **سمات بمتغيرات CSS** — متوافق مع `tokens.css` في Powerduck والوضعين الفاتح والداكن
