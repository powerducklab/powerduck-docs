# AI · Models

يتطلب Powerduck، بما في ذلك تطبيق سطح المكتب، تسجيل الدخول عبر Google OAuth أو GitHub. تبقى الملفات على القرص. يرسل تحليل الذكاء الاصطناعي السياق المحدد إلى مزودي الخدمة الذين تديرهم Powerduck. لم تعد عناوين النماذج ومفاتيح API المخصصة مدعومة.

Free: ‏300,000 credits يوميًا مع إعادة الضبط عند 00:00 UTC. ‏Pro: ‏39 دولارًا شهريًا و18,000,000 credits كل 7 أيام. ‏Max: ‏99 دولارًا شهريًا و60,000,000 credits كل 7 أيام. تبدأ الدورة من بداية الاشتراك الأولى، مستقلة عن الفاتورة الشهرية. لا يُرحّل الرصيد. يشترك سطح المكتب وAI Chat في الخطة الشخصية؛ لم تعد التراخيص الدائمة ومفاتيح التفعيل تُباع.
