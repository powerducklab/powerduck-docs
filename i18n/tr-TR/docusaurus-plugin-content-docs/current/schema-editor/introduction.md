# @powerduck/schema-editor

JSON, YAML ve JavaScript için şema destekli Monaco düzenleyicisi. Herhangi bir JSON Schema ile satır içi öneriler, açılır tamamlama, enum listeleri, otomatik örnek doldurma ve şema tanılaması sunar.

- **Paket adı:** `@powerduck/schema-editor`
- **Sürüm:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Lisans:** MIT

## Özellikler

- **Üç dil** — JSON, YAML ve JavaScript (Postman test betikleri)
- **Şema tabanlı tamamlama** — Herhangi bir JSON Schema’dan enum listeleri, özellik adları ve otomatik örnek doldurma
- **Hayalet metin** — Beklenen sonraki belirteç için satır içi öneriler
- **Şema tanılaması** — Satır içinde doğrulama hataları ve durum çubuğu
- **Monaco tabanlı** — Tüm düzenleyicilerde sözdizimi vurgulama, mini harita ve komut paleti
- **Açık ve koyu temalar** — `powerduck-light` / `powerduck-dark`
- **Bağımsız çekirdek** — Şema çözümleme, örnek üretimi ve tanılama React olmadan çalışır
