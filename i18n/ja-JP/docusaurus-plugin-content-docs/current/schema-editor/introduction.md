# @powerduck/schema-editor

JSON、YAML、JavaScript 向けのスキーマ対応 Monaco エディターです。任意の JSON Schema に基づき、ゴーストテキスト、補完ポップアップ、列挙値のドロップダウン、サンプルの自動入力、スキーマ診断を提供します。

- **パッケージ名:** `@powerduck/schema-editor`
- **バージョン:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **ライセンス:** MIT

## 機能

- **3 つの言語** — JSON、YAML、JavaScript（Postman テストスクリプト）
- **スキーマに基づく補完** — 任意の JSON Schema から列挙値のドロップダウン、プロパティ名、サンプルの自動入力を提供
- **ゴーストテキスト** — 次に入力すべきトークンの候補をインラインで表示
- **スキーマ診断** — 検証エラーをインライン表示し、ステータスバーも提供
- **Monaco を採用** — すべてのエディターで構文ハイライト、ミニマップ、コマンドパレットを利用可能
- **ライト／ダークテーマ** — `powerduck-light` / `powerduck-dark`
- **独立したコア** — スキーマ解決、サンプル生成、診断は React なしで動作
