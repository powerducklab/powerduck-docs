# Powerduck Cloud

Powerduck Cloud आपकी OpenAPI फ़ाइल को **साझा करने योग्य** बनाता है। विनिर्देश जोड़ें, उपलब्ध कराने वाली कार्रवाइयाँ चुनें और तैयार दस्तावेज़ों तथा प्रबंधित MCP सर्वर के स्थायी लिंक साझा करें। इन सेवाओं को खुद होस्ट या संचालित करने की ज़रूरत नहीं है।

यह डेस्कटॉप क्लाइंट वाला ही API अनुबंध पर आधारित, AI-सहायता प्राप्त कार्यप्रवाह है, जो टीमों और API उपयोगकर्ताओं के लिए ऑनलाइन उपलब्ध है। Free प्लान में तय सीमाओं के भीतर दस्तावेज़ और MCP होस्टिंग शामिल हैं; सशुल्क प्लान में अधिक क्षमता, Git स्रोत और कस्टम डोमेन मिलते हैं। आपका व्यावसायिक API आपके अपने बैकएंड पर ही चलता है।

## काम करने का तरीका

1. **विनिर्देश जोड़ें:** फ़ाइल अपलोड करें, Git रिपॉज़िटरी बताएँ या URL पेस्ट करें। आप वेबसाइट पर प्रक्रिया शुरू करके तैयार होने पर खाते में साइन इन कर सकते हैं; फ़ाइल दोबारा अपलोड नहीं करनी पड़ेगी।
2. **उपलब्ध कराने वाली कार्रवाइयाँ चुनें।** हर कार्रवाई को अलग से चालू या बंद करें; मूल फ़ाइल कभी नहीं बदली जाती।
3. **दस्तावेज़ का लिंक तुरंत खोलें।** API दस्तावेज़ डिफ़ॉल्ट रूप से चालू रहते हैं। प्रबंधित MCP एंडपॉइंट का अलग स्विच है और जब तक आप एजेंटों को टूल उपलब्ध कराने का निर्णय नहीं लेते, वह बंद रहता है।
4. **पहुँच नियंत्रित करें।** दस्तावेज़ देखने के लिए पासवर्ड और समाप्ति समय सेट करें तथा एजेंटों के लिए अलग MCP पहुँच कुंजी बनाएँ।
5. **प्रकाशित करें और साझा करें।** मौजूदा संस्करण का तैयार आर्टिफ़ैक्ट प्रकाशित करें ताकि लिंक काम करें; उन्नत नियंत्रण भी आसानी से उपलब्ध रहते हैं।
6. **अपडेट करते रहें।** हर बदलाव नया संस्करण बनाता है, जिसकी तुलना की जा सकती है या जिसे वापस बहाल किया जा सकता है। Git स्रोत अपडेट होने पर सिंक हो सकते हैं।
7. **जीवनचक्र सँभालें।** दस्तावेज़ रोकें, फिर सक्रिय करें या संग्रहित करें; उसकी स्थिति, संस्करण और स्रोत एक नज़र में देखें।

## उपलब्ध सुविधाएँ

- **दस्तावेज़ों के स्थायी लिंक**, जो नए संस्करण प्रकाशित होने पर भी काम करते रहते हैं;
- **प्रबंधित MCP एंडपॉइंट**, जिससे दूसरे उपयोगकर्ताओं के AI एजेंट आपकी चुनी हुई कार्रवाइयाँ खोज और कॉल कर सकते हैं;
- **हर कार्रवाई का अलग नियंत्रण**, ताकि आंतरिक या अधूरे एंडपॉइंट सार्वजनिक इंटरफ़ेस पर उपलब्ध न हों;
- देखने के पासवर्ड, समाप्ति समय और MCP पहुँच कुंजियों से **पहुँच नियंत्रण**;
- **संस्करण इतिहास**, जिसमें तुलना और बहाली की सुविधा है तथा मूल सामग्री नहीं मिटती;
- **Git सिंक**, जिससे रिपॉज़िटरी के अपडेट का नया होस्ट किया गया संस्करण बनता है;
- **कस्टम डोमेन**, उप-पथ वाली व्यवस्था सहित, ताकि अनुभव आपके ब्रांड के अनुरूप हो।

### एक दस्तावेज़, कई संस्करण

हर संपादन मूल संस्करण को बदलने के बजाय नया संस्करण बनाता है। आप संस्करणों की तुलना कर सकते हैं, पिछले संस्करण पर लौट सकते हैं और किसी ज्ञात स्थिति से दस्तावेज़ों तथा MCP को फिर प्रकाशित कर सकते हैं। दस्तावेज़ और MCP हमेशा किसी निश्चित दस्तावेज़ और संस्करण से जुड़े होते हैं, किसी अस्पष्ट “नवीनतम” संस्करण से नहीं।

### लिंक क्यों नहीं खुल सकता है

दस्तावेज़ या MCP लिंक तभी काम करता है जब तीन शर्तें पूरी हों। दस्तावेज़ का कार्यक्षेत्र तीनों दिखाता है और पहली अधूरी शर्त को चिह्नित करता है:

1. दस्तावेज़ **सक्रिय** हो: उसे रोकने पर दस्तावेज़ और MCP दोनों एक साथ ऑफ़लाइन हो जाते हैं;
2. साझा की जा रही सेवा **चालू** हो: दस्तावेज़ और MCP के अलग स्विच हैं; डिफ़ॉल्ट रूप से दस्तावेज़ चालू और MCP बंद रहता है;
3. मौजूदा आर्टिफ़ैक्ट **प्रकाशित** हो: संस्करण जोड़ने या उपलब्ध कार्रवाइयाँ बदलने के बाद यह अपने आप बनता है, इसलिए सामान्यतः कोई अतिरिक्त कदम नहीं चाहिए; ज़रूरत होने पर मैन्युअल प्रकाशन भी उपलब्ध है।

इन तीन शर्तों के अलावा, देखने के पासवर्ड, समाप्ति समय या MCP पहुँच कुंजी की जाँच भी लागू होती है।

## साइन इन और स्वामित्व

**Google** या **GitHub** से साइन इन करें। OAuth प्रक्रिया के बाद Powerduck सुरक्षित HttpOnly कुकी से अपना सत्र बनाता है; प्रदाता का टोकन आपकी स्थायी पहचान के रूप में इस्तेमाल नहीं होता। सभी संसाधन किसी **संगठन** के होते हैं। निजी संगठन अपने आप बन जाता है; बाद में टीम बिना व्यवस्था को दोबारा बनाए साझा संगठन इस्तेमाल कर सकती है।

## कंसोल

- **डैशबोर्ड:** विनिर्देश जोड़ें और हाल के दस्तावेज़ देखें; त्वरित लिंक तथा शुरू और बंद करने की कार्रवाइयाँ भी उपलब्ध हैं;
- **प्रोजेक्ट:** दस्तावेज़ व्यवस्थित करें;
- **दस्तावेज़ कार्यक्षेत्र:** स्थिति, दस्तावेज़, MCP, उपलब्ध कार्रवाइयाँ, संस्करण, स्रोत और डोमेन स्पष्ट नाम वाले अलग-अलग खंडों में देखें;
- **बिलिंग:** सदस्यता की स्थिति और ऑर्डर अलग-अलग देखें;
- **Hub:** सार्वजनिक दस्तावेज़ और MCP सर्वर प्रकाशित करें तथा खोजें;
- **सेटिंग्स** और **गतिविधि:** प्रोफ़ाइल, प्राथमिकताएँ और ऑडिट लॉग देखें।

सार्वजनिक दस्तावेज़ों के पाठक अलग दस्तावेज़ व्यूअर का उपयोग करते हैं और उन्हें Powerduck खाते की ज़रूरत नहीं होती। देखने का पासवर्ड सेट हो तो उन्हें वह दर्ज करना होगा; दस्तावेज़ का पासवर्ड और खाते में साइन इन करना दो अलग आवश्यकताएँ हैं।

## Cloud और डेस्कटॉप क्लाइंट की तुलना

| | डेस्कटॉप क्लाइंट | Cloud |
|---|---|---|
| कहाँ चलता है | आपके कंप्यूटर पर | होस्ट की गई सेवा |
| भुगतान मॉडल | एकमुश्त भुगतान वाला स्थायी लाइसेंस | मुफ़्त प्लान और सशुल्क सदस्यताएँ |
| क्या मिलता है | लाइसेंस कुंजी, जो एक बार दिखाई जाती है | प्लान के अनुसार सुविधाएँ, बिना लाइसेंस कुंजी के |
| सबसे उपयुक्त उपयोग | संपूर्ण स्थानीय और ऑफ़लाइन कार्यक्षेत्र | ऑनलाइन साझा करना और प्रकाशित करना |

दोनों उत्पाद एक-दूसरे के पूरक हैं। Cloud में Free प्लान उपलब्ध है; सशुल्क Cloud सदस्यताएँ और डेस्कटॉप लाइसेंस अलग-अलग खरीदे जाते हैं। [बिलिंग](./billing.md) देखें।
