# @powerduck/schema-editor

JSON, YAML और JavaScript के लिए स्कीमा-सक्षम Monaco एडिटर। किसी भी JSON Schema के आधार पर इनलाइन सुझाव, पॉप-अप ऑटोकम्प्लीट, एनम ड्रॉपडाउन, उदाहरणों का अपने-आप भरना और स्कीमा डायग्नोस्टिक्स प्रदान करता है।

- **पैकेज का नाम:** `@powerduck/schema-editor`
- **संस्करण:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **लाइसेंस:** MIT

## सुविधाएँ

- **तीन भाषाएँ** — JSON, YAML और JavaScript (Postman टेस्ट स्क्रिप्ट)
- **स्कीमा-आधारित ऑटोकम्प्लीट** — किसी भी JSON Schema से एनम ड्रॉपडाउन, प्रॉपर्टी के नाम और उदाहरणों का अपने-आप भरना
- **घोस्ट टेक्स्ट** — अगले अपेक्षित टोकन के लिए इनलाइन सुझाव
- **स्कीमा डायग्नोस्टिक्स** — वैलिडेशन की त्रुटियाँ उसी पंक्ति में, साथ में स्टेटस बार
- **Monaco पर आधारित** — सभी एडिटर में सिंटैक्स हाइलाइटिंग, मिनीमैप और कमांड पैलेट
- **हल्की और गहरी थीम** — `powerduck-light` / `powerduck-dark`
- **स्वतंत्र कोर** — स्कीमा रिज़ॉल्यूशन, नमूने बनाना और डायग्नोस्टिक्स React के बिना काम करते हैं
