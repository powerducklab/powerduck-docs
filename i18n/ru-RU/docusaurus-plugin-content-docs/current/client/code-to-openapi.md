# Генерация OpenAPI из существующего проекта

В настольном приложении выберите **Сканировать код в OpenAPI** (бета), укажите локальную папку исходного кода и нажмите **Начать сканирование**. Начните с небольшого сервиса. Прежде чем использовать созданную спецификацию, проверьте обнаруженные маршруты, параметры и ответы.

Статическое сканирование может не определить схемы ответов, если обработчики зависят от динамического кода или недоступных зависимостей. «Подтвердить вручную» фиксирует вашу проверку, но не восстанавливает недостающие типы. Изменяйте контракт API на основе проверяемых данных или попросите ИИ проверить выбранный обработчик. При этом выбранный исходный код и контекст отправляются настроенному поставщику модели.

Сохраните результат в новый файл. Не заменяйте существующий контракт без проверки изменений. Затем запустите [пример проверки контракта](/docs/ru-RU/client/contract-example/) для работающего бэкенда или подключите [агента программирования](/docs/ru-RU/client/coding-agent/). Успешное сканирование не доказывает соответствие реализации контракту.

Этот процесс доступен только в настольном приложении; поддержка языков и фреймворков зависит от сканера. Для статического анализа ключ модели не нужен. Неразрешённые результаты следует считать неизвестными, а не установленными фактами.
