# مكتبات مفتوحة المصدر

يتكوّن Powerduck من حزم npm صغيرة قابلة للتركيب. يستخدم تطبيق سطح المكتب والخدمة السحابية المكتبات نفسها، فتعمل المكوّنات ذاتها محليًا أو عبر الشبكة أو داخل أدواتك الخاصة.

تُنشر كل حزمة بشكل مستقل، مع تعليمات تثبيت ومرجع API وأمثلة خاصة بها. توضح هذه الصفحة وظيفة كل حزمة وكيف تتكامل الحزم.

## تنظيم الطبقات

```text
Powerduck / Cloud
        ↓
واجهات قابلة للتضمين
        ↓
مسارات العمل
        ↓
الأساس
```

يشكّل المحلّل والمحوّلات الطبقة الأساسية، وتُبنى عليها مسارات العمل، ثم تأتي الواجهات القابلة للتضمين. الاعتماد على قاعدة مشتركة بدل إعادة تنفيذ التحليل في كل حزمة يحافظ على اتساق السلوك.

## الحزم

### الأساس

| الحزمة | الوظيفة |
|---|---|
| [`@powerduck/openapi-parser`](../openapi-parser/introduction.md) | تحليل مستندات OpenAPI/Swagger والتحقق منها وترقيتها |
| [`@powerduck/conf-patch`](../conf-patch/introduction.md) | تطبيق تعديلات إعدادات منظّمة ومتحقق منها |
| [`@powerduck/x-to-openapi`](../x-to-openapi/introduction.md) | تحويل صيغ أخرى، مثل cURL وPostman، إلى OpenAPI |

### مسارات العمل

| الحزمة | الوظيفة |
|---|---|
| [`@powerduck/openapi-cli`](../openapi-cli/introduction.md) | مسارات عمل متعددة البروتوكولات عبر سطر الأوامر، بما فيها تشغيل السيناريوهات |
| [`@powerduck/openapi-codegen`](../openapi-codegen/introduction.md) | توليد شيفرة العميل ومخرجات أخرى من المواصفة |
| [`@powerduck/openapi-mcp-server`](../openapi-mcp-server/introduction.md) | تقديم مواصفة OpenAPI كخادم MCP |
| [`@powerduck/openapi-request`](../openapi-request/introduction.md) | تنفيذ الطلبات الموصوفة في المواصفة |

### واجهات قابلة للتضمين

| الحزمة | الوظيفة |
|---|---|
| [`@powerduck/oas-document`](../oas-document/introduction.md) | عرض OpenAPI كتوثيق مقروء، مع نقطة دخول React |
| [`@powerduck/md-editor`](../md-editor/introduction.md) | محرّر Markdown قابل للتضمين |
| [`@powerduck/schema-editor`](../schema-editor/introduction.md) | محرّر JSON Schema قابل للتضمين |
| [`@powerduck/tree`](../tree/introduction.md) | مكوّن شجري للبيانات المنظّمة |
| [`@powerduck/workspace-yaml`](../workspace-yaml/introduction.md) | تكامل YAML لمساحة العمل |

## اختيار الحزمة المناسبة

- **قراءة ملف OpenAPI أو التحقق منه أو ترقيته:** ابدأ بـ `openapi-parser`.
- **تحويل cURL أو مجموعة Postman إلى OpenAPI:** استخدم `x-to-openapi`.
- **تشغيل سيناريوهات أو مسارات متعددة البروتوكولات عبر سطر الأوامر أو CI:** استخدم `openapi-cli`.
- **توليد شيفرة العميل:** استخدم `openapi-codegen`.
- **إتاحة API كأدوات لوكيل ذكاء اصطناعي:** استخدم `openapi-mcp-server`.
- **تضمين التوثيق المعروض في تطبيق React:** استخدم `oas-document` ونقطة دخول React وملف CSS الخاص به.
- **تضمين محرّر:** استخدم `md-editor` أو `schema-editor`.

## مشاركة الإمكانات مع الوكلاء

تتيح حزمة خادم MCP أيضًا لوكلاء الذكاء الاصطناعي الخارجيين استخدام إمكانات Powerduck. تُعرَض عمليات المواصفة المقدمة عبر `openapi-mcp-server` كأدوات MCP، فيستطيع الوكيل استدعاء العقد نفسه المستخدم للتوثيق وتوليد الشيفرة مباشرةً. وهكذا يشترك تطبيق سطح المكتب وCloud والأدوات المتوافقة مع MCP في تعريف مرجعي موحّد.

## حول الأمثلة

كُتبت أمثلة الشيفرة وفق API الفعلية للحزمة، بهدف تشغيلها كما هي. عند ترقية الحزمة، راجع ملاحظات الإصدار لمعرفة المعلمات الحالية بدل نسخ مقاطع من إصدارات قديمة.

استخدم الشريط الجانبي للوصول إلى التثبيت والإعدادات ومرجع API الكامل لكل حزمة.
