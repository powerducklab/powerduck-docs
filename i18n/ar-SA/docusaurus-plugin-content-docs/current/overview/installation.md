# التثبيت والبدء

نزّل macOS Apple Silicon أو Intel أو Windows أو Linux AppImage من الموقع الرسمي. تحقق من المصدر والناشر ولا تعطّل الحماية. سجّل في الموقع وعد إلى التطبيق ثم استورد API أو اختر مشروع كود. المتصفح لتجربة API؛ تحليل الملفات والأوامر المحلية يحتاج سطح المكتب.

[Powerduck](https://www.powerduck.com/download.html)

## الذكاء المدمج والاستخدام

سجّل عبر Google أو GitHub واستخدم النموذج المدمج فقط دون اختيار نموذج أو مفاتيح شخصية أو نقاط نهاية مخصصة. يرسل عمل AI المطلوب السياق المحدد إلى مزودين مُدارين. استبعاد مسارات التبعيات والبناء وبيانات الاعتماد الشائعة لا يضمن خلو المصدر من الأسرار.

## macOS · Windows · Linux

macOS 11+ · Windows 10+ · Linux · Electron 37

- macOS: `.dmg` · `arm64` / `x64`
- Windows: NSIS `.exe` · SmartScreen
- Linux: `.AppImage` · `x64`

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```
