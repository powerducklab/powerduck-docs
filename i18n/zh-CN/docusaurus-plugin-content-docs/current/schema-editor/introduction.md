# @powerduck/schema-editor

支持模式感知的 Monaco 编辑器，适用于 JSON、YAML 和 JavaScript。可由任意 JSON Schema 驱动，提供行内预览建议、弹出补全、枚举下拉框、示例自动填充和模式诊断。

- **包名:** `@powerduck/schema-editor`
- **版本:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **许可证:** MIT

## 功能

- **三种语言** — JSON、YAML 和 JavaScript（Postman 测试脚本）
- **模式驱动的补全** — 根据任意 JSON Schema 提供枚举下拉框、属性名和示例自动填充
- **行内预览建议** — 以内联方式提示下一个预期的词法单元
- **模式诊断** — 在行内显示验证错误，并提供状态栏
- **基于 Monaco** — 所有编辑器均支持语法高亮、缩略图和命令面板
- **浅色与深色主题** — `powerduck-light` / `powerduck-dark`
- **独立核心** — 模式解析、样本生成和诊断无需 React 即可运行
