# التثبيت

يتطلب Powerduck، بما في ذلك تطبيق سطح المكتب، تسجيل الدخول عبر Google OAuth أو GitHub. تبقى الملفات على القرص. يرسل تحليل الذكاء الاصطناعي السياق المحدد إلى مزودي الخدمة الذين تديرهم Powerduck. لم تعد عناوين النماذج ومفاتيح API المخصصة مدعومة.

## التنزيل

احصل على المُثبِّت لمنصتك من [موقع Powerduck](https://www.powerduck.com/#download). تُنتَج النسخ التالية باستخدام `electron-builder`.

| المنصة | المُثبِّت | المعماريات |
|---|---|---|
| macOS | `.dmg` (و`.zip` للتحديثات التلقائية) | Apple Silicon (`arm64`) وIntel (`x64`) |
| Windows | مُثبِّت NSIS (`.exe`) | `x64` |
| Linux | AppImage (`.AppImage`) | `x64` |

## macOS

1. افتح `.dmg` واسحب Powerduck إلى **التطبيقات**.
2. عند التشغيل الأول، قد يطلب macOS تأكيد فتح تطبيق نُزّل من خارج App Store. تحقّق من أنه جاء من صفحة التنزيل الرسمية قبل فتحه؛ ولا تعطّل فحوص أمان النظام.
3. تُنشَر نسختان: `arm64` لـ Apple Silicon (سلسلة M) و`x64` لـ Mac Intel. نزّل المناسب.

## Windows

1. شغّل مُثبِّت NSIS (`.exe`) واتبع الإعداد.
2. إذا عرض SmartScreen تحذيرًا بشأن ناشر غير معروف، فتحقّق أولًا من أن المثبّت جاء من صفحة التنزيل الرسمية. لا تتابع إلا بعد التأكد من المصدر؛ ولا تتجاوز التحذير لتنزيل غير موثوق.

## Linux

1. نزّل `.AppImage`.
2. اجعله قابلاً للتنفيذ ثم شغّله.

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```

يعمل AppImage دون تثبيت على النظام. تحتاج بعض التوزيعات إلى FUSE للتركيب.

## ما الذي يعمل على جهازك

عميل سطح المكتب تطبيق Electron من جزأين.

- **العملية الرئيسية** (Node.js)، التي تدير الوصول إلى الملفات وطلبات HTTP الخارجية وخادم المحاكاة المحلي واتصالات قواعد البيانات والطرفية المدمجة.
- **العارض** (مساحة عمل React)، التي تعرض المواصفة ومحادثة الذكاء الاصطناعي والأدوات.

يتطلب Powerduck، بما في ذلك تطبيق سطح المكتب، تسجيل الدخول عبر Google OAuth أو GitHub. تبقى الملفات على القرص. يرسل تحليل الذكاء الاصطناعي السياق المحدد إلى مزودي الخدمة الذين تديرهم Powerduck. لم تعد عناوين النماذج ومفاتيح API المخصصة مدعومة.
