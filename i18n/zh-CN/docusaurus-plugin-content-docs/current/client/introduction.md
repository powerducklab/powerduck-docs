# 桌面客户端

桌面客户端是 AI 原生工作流在你自己机器上发生的地方。你从仓库打开一个 `openapi.yaml`，说出你想要的结果，然后审阅它——无需在规范编辑器、HTTP 客户端、Mock 工具、文档生成器和测试运行器之间切换，开始使用也无需云账号。

你始终掌握控制权：助手提议，你批准。

## 工作区中的一天

以下正是客户端围绕其打造的那些时刻。

- **打开规范并把握全局。** 助手读取当前文档，立即建议你可以做什么——要填补的空缺、要补全的文档、要测试的流程。
- **创建 API。** 描述资源，助手提出接口；持续细化同一个操作——加个参数、收紧响应、调整状态码——它会停留在该 API 上，而不是在文档中漂移。
- **准备测试数据。** 根据模式生成逼真的示例数据，让请求和场景有具体值可用。
- **运行单个请求或完整场景。** 调试一次调用，或把多个接口串成端到端流程，并获得一份可分享的报告，说明哪些通过、哪些失败。
- **在后端就绪前继续推进。** 启动一个本地 Mock，在真实服务开发期间根据契约应答。
- **把 API 交给编程智能体。** 把规范变成 MCP 服务器，让 AI 工具能够以正确的参数发现并调用正确的操作。
- **看清 API 背后的数据库。** 从规范推导表、关系和 SQL，与真实数据库比对，发现将会发生的变化。
- **不离开对话即可更改设置。** 只需开口要求，就能切换主题或语言、设置代理或管理环境变量。

## 各形态及其用途

一份文档驱动每个形态；一个紧凑的切换器在它们之间移动。

| 形态 | 你用它做什么 |
|---|---|
| [**规范**](./design) | 主形态：AI 对话、文档和实时预览 |
| [**请求工作区**](./debug) | 发送并检查真实 HTTP 请求，支持标签页和环境 |
| [**场景测试**](./scenario-testing) | 把接口串成流程，运行它们并获得报告 |
| [**文档**](./protocols) | 把规范阅读为渲染后的 API 文档 |
| [**MCP**](./protocols) | 检查并使用从规范推导的 MCP 服务器 |
| [**Mock 服务器**](./mock-server) | 在 API 开发期间运行本地 Mock |
| [**数据模型**](./data-model) | 推导表和关系，与数据库比对，生成 SQL |
| [**设置**](./settings) | 主题、语言、代理、证书和工作区偏好 |

## 助手如何与你协作

你用自然语言描述意图；助手选择合适的能力，确定性引擎对其校验，你通过卡片批准。模型从不会自行编辑文档。

- 规范改动以带有精细操作的**补丁卡片**呈现；编辑已有操作时只改动你要求的字段；
- 只读动作——列出操作、获取模式、运行查询——返回助手据以支撑其回答的事实；
- 写入动作在运行前要求确认。

模型**由你配置**：把应用指向任何兼容 OpenAI 的服务商，并在设置中选择它。参见 [AI 与模型](./ai-models)。

## 本地优先为什么对你重要

- **你的真实文件。** 应用打开、编辑并保存磁盘上的实际文件，并跟踪本地变更。
- **没有 CORS 墙。** 请求通过本地进程而非网页视图发出，因此跨域限制不会阻挡你的调用。
- **提示词和密钥保持私密。** 它们在本地处理，从不出现在浏览器网络面板中。
- **可离线工作。** 设计、Mock 和文档无需网络；仅实时请求、Git 同步或托管模型才需要网络。
- **本地运行时。** Mock、场景运行器、数据库访问和终端都在你的机器上运行。

## 桌面授权

桌面客户端以**一次性、永久授权**的方式出售：一次购买，永久拥有，完全离线工作，无需账号。授权码在购买时生成并仅展示一次。它与按月订阅托管服务的 Powerduck Cloud 相互独立。参见 [Cloud 账单](../cloud/billing)。
