# 変更を理解する

Powerduck は、AI が大量のコードを生成する中で、変更内容と周辺コードを確認し、対応すべき問題を判断するためのデスクトップアプリです。ホームから API ワークスペースとコードレビューを個別に開けます。

## API ワークスペース

OpenAPI YAML／JSON を読み込み、操作の設計、リクエスト送信、応答確認、シナリオ、本機 Mock、データモデル、ドキュメントを扱います。MCP と公開は別の操作です。定義の読み込みだけでは業務バックエンドはデプロイされません。

## コードレビュー

コードフォルダーを選ぶと構造ビューが開きます。ファイルを選択して全体を読み、ソースのみ、全体比較、変更のみを切り替えます。追加・削除行、文字単位の強調、変更ナビゲーション、検索で編集箇所を確認できます。

## 内蔵 AI と利用範囲

Google／GitHub でログインし、内蔵モデルを利用します。モデル選択、独自キーやエンドポイントはありません。AI 要求時に選択した文脈を管理されたプロバイダーへ送信します。一般的な依存・ビルド・認証情報パスを除外しても、ソース内の秘密情報を完全には検出できません。
