# Installare e iniziare

Scarica dal sito ufficiale macOS Apple Silicon/Intel, Windows o Linux AppImage. Verifica origine e produttore senza disattivare la sicurezza. Accedi nel sito e torna all’app; importa API o scegli codice. Il browser mostra flussi API; analisi locale e comandi richiedono il desktop.

[Powerduck](https://www.powerduck.com/download.html)

## IA integrata e utilizzo

Accedi con Google o GitHub. Solo modello integrato, senza selettore, chiavi proprie o endpoint personalizzati. Il lavoro IA richiesto invia il contesto scelto a fornitori gestiti. Le comuni cartelle di dipendenze, build e credenziali sono escluse, ma il sorgente può ancora contenere segreti.

## macOS · Windows · Linux

macOS 11+ · Windows 10+ · Linux · Electron 37

- macOS: `.dmg` · `arm64` / `x64`
- Windows: NSIS `.exe` · SmartScreen
- Linux: `.AppImage` · `x64`

```bash
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage
```
