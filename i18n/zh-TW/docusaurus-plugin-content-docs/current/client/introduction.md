# 桌面用戶端

桌面用戶端是 AI 原生工作流在你自己機器上發生的地方。你從儲存庫打開一個 `openapi.yaml`，說出你想要的結果，然後審閱它——無需在規範編輯器、HTTP 用戶端、Mock 工具、文件產生器和測試執行器之間切換，開始使用也無需雲端帳號。

你始終掌握控制權：助手提議，你核准。

## 工作區中的一天

以下正是用戶端圍繞其打造的那些時刻。

- **打開規範並把握全域。** 助手讀取當前文件，立即建議你可以做什麼——要填補的空缺、要補全的文件、要測試的流程。
- **建立 API。** 描述資源，助手提出介面；持續細化同一個操作——加個參數、收緊回應、調整狀態碼——它會停留在該 API 上，而不是在整份文件中漂移。
- **準備測試資料。** 根據模式產生逼真的範例資料，讓請求和場景有具體值可用。
- **執行單個請求或完整場景。** 除錯一次呼叫，或把多個介面串成端到端流程，並獲得一份可分享的報告，說明哪些通過、哪些失敗。
- **在後端就緒前繼續推進。** 啟動一個本機 Mock，在真實服務開發期間根據合約應答。
- **把 API 交給程式設計代理。** 把規範變成 MCP 伺服器，讓 AI 工具能夠以正確的參數發現並呼叫正確的操作。
- **看清 API 背後的資料庫。** 從規範推導表、關係和 SQL，與真實資料庫比對，發現將會發生的變化。
- **不離開對話即可變更設定。** 只需開口要求，就能切換主題或語言、設定代理或管理環境變數。

## 各形態及其用途

一份文件驅動每個形態；一個緊湊的切換器在它們之間移動。

| 形態 | 你用它做什麼 |
|---|---|
| [**規範**](/docs/client/design) | 主形態：AI 對話、文件和即時預覽 |
| [**請求工作區**](/docs/client/debug) | 發送並檢查真實 HTTP 請求，支援標籤頁和環境 |
| [**場景測試**](/docs/client/scenario-testing) | 把介面串成流程，執行它們並獲得報告 |
| [**文件**](/docs/client/protocols) | 把規範閱讀為渲染後的 API 文件 |
| [**MCP**](/docs/client/protocols) | 檢查並使用從規範推導的 MCP 伺服器 |
| [**Mock 伺服器**](/docs/client/mock-server) | 在 API 開發期間執行本機 Mock |
| [**資料模型**](/docs/client/data-model) | 推導表和關係，與資料庫比對，產生 SQL |
| [**設定**](/docs/client/settings) | 主題、語言、代理、憑證和工作區偏好 |

## 助手如何與你協作

你用自然語言描述意圖；助手選擇合適的能力，確定性引擎對其校驗，你透過卡片核准。模型從不會自行編輯文件。

- 規範變更以帶有精細操作的**補丁卡片**呈現；編輯已有操作時只改動你要求的欄位；
- 只讀動作——列出操作、取得模式、執行查詢——回傳助手據以支撐其回答的事實；
- 寫入動作在執行前要求確認。

模型**由你配置**：把應用程式指向任何相容 OpenAI 的服務商，並在設定中選擇它。參見 [AI 與模型](/docs/client/ai-models)。

## 本機優先為什麼對你重要

- **你的真實檔案。** 應用程式打開、編輯並儲存磁碟上的實際檔案，並追蹤本機變更。
- **沒有 CORS 牆。** 請求透過本機程序而非網頁檢視發出，因此跨域限制不會阻擋你的呼叫。
- **提示詞和密鑰保持私密。** 它們在本機處理，從不出現在瀏覽器網路面板中。
- **可離線工作。** 設計、Mock 和文件無需網路；僅即時請求、Git 同步或託管模型才需要網路。
- **本機執行環境。** Mock、場景執行器、資料庫存取和終端機都在你的機器上執行。

## 桌面授權

桌面用戶端以**一次性、永久授權**的方式出售：一次購買，永久擁有，完全離線工作，無需帳號。授權碼在購買時產生並僅展示一次。它與按月訂閱託管服務的 Powerduck Cloud 相互獨立。參見 [Cloud 帳單](/docs/cloud/billing)。
