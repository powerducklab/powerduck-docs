# @powerduck/schema-editor

Editor Monaco compatível com esquemas para JSON, YAML e JavaScript. Usa qualquer JSON Schema para oferecer sugestões em linha, preenchimento em pop-up, listas de valores enumerados, preenchimento automático de exemplos e diagnósticos de esquema.

- **Nome do pacote:** `@powerduck/schema-editor`
- **Versão:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Licença:** MIT

## Recursos

- **Três linguagens** — JSON, YAML e JavaScript (scripts de teste do Postman)
- **Preenchimento orientado por esquema** — Listas de valores enumerados, nomes de propriedades e preenchimento automático de exemplos a partir de qualquer JSON Schema
- **Texto fantasma** — Sugestões em linha para o próximo token esperado
- **Diagnósticos de esquema** — Erros de validação em linha e barra de status
- **Baseado no Monaco** — Realce de sintaxe, minimapa e paleta de comandos em todos os editores
- **Temas claro e escuro** — `powerduck-light` / `powerduck-dark`
- **Núcleo independente** — Resolução de esquemas, geração de exemplos e diagnósticos sem React
