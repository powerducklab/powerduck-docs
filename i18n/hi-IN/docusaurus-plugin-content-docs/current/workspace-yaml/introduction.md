# @powerduck/workspace-yaml

workspace.yaml और OpenAPI 3.2 YAML फ़ाइलें भरोसेमंद तरीके से तैयार करें।

दो-परत वाला आर्किटेक्चर:
- **कोर परत**: ब्राउज़र में सुरक्षित रूप से चलने वाले प्योर फ़ंक्शन YAML सामग्री की स्ट्रिंग बनाते हैं। फ़ाइल सिस्टम तक पहुँच की ज़रूरत नहीं होती।
- **फ़ाइल परत**: Node.js / Electron में कोर परत के साथ एटॉमिक राइट, फ़ाइल लॉकिंग और पाथ नॉर्मलाइज़ेशन जोड़ती है।

- **पैकेज का नाम:** `@powerduck/workspace-yaml`
- **संस्करण:** <img src="https://img.shields.io/npm/v/@powerduck/workspace-yaml"/>
- **लाइसेंस:** MIT

यह लाइब्रेरी **केवल फ़ाइलों को शुरुआती रूप से तैयार करती है** और नई फ़ाइल बनाने या मैन्युअल रूप से बनाने के लिए है। यह YAML फ़ाइलों को पढ़ने, पैच लगाने या अपडेट करने की कार्यक्षमता दोबारा लागू **नहीं** करती। इन कामों के लिए उपयोग करें: [`@powerduck/conf-patch`](https://www.npmjs.com/package/@powerduck/conf-patch).
