# ربط OpenAPI بوكيل برمجة

استخدم **MCP للمطورين** لتمكين وكيل البرمجة من فحص العقد والتحقق من الواجهة الخلفية. أما **API-to-MCP** فيتيح عمليات API كأدوات قابلة للاستدعاء، وهو مسار عمل مختلف.

1. افتح ملف YAML/JSON باستخدام **فتح** في تطبيق سطح المكتب. احفظ نسخة مستقلة قبل بدء التجربة.
2. افتح **MCP والبرمجة** للمواصفة الحالية. ويمكنك بدلاً من ذلك تشغيل `npm ci` و`npm run build` من نسخة محلية لمستودع MCP للمطورين.
3. اضبط خادم MCP يستخدم stdio في وكيلك، مع الملف التنفيذي `node` والوسيطات `/absolute/path/dev-mcp-server/dist/cli.mjs` و`--spec` و`/absolute/path/openapi.yaml`. استخدم مسارات مطلقة فعلية، ولا تنسخ القيم التوضيحية كما هي.
4. اطلب من الوكيل قراءة عملية ومخطط استجابتها قبل تعديل الواجهة الخلفية. وبعد التعديل، اطلب منه استدعاء `run_contract_tests` مع تحديد قيمة `baseUrl` المحلية للواجهة الخلفية صراحةً.
5. راجع تأكيدات الاختبار الواردة في التقرير والتعديل البرمجي المقترح. أعد تشغيل الاختبارات بعد تطبيق الإصلاح الذي وافقت عليه.

يتطلب خادم MCP للمطورين الإصدار Node.js 22.12.0 أو أحدث. قد يرسل وكيلك نتائج الأدوات أو سياق الشيفرة إلى النموذج البعيد الذي أعددته. لا تحتاج إلى نموذج لإجراء الطلبات المحلية يدويًا أو اختبارات العقد. يفرض مزودك رسوم استخدام مفتاحك الخاص، بينما تُحتسب أرصدة النماذج المستضافة بشكل منفصل. لا يتطلب العمل المحلي اشتراكًا في Cloud.
