# البدء السريع للسحابة

ينقل هذا التدفّق مواصفة من جهازك إلى صفحة توثيق قابلة للمشاركة ونقطة نهاية MCP.

## 1. تسجيل الدخول

في صفحة الدخول، تابع بـ**Google** أو **GitHub**. بعد مصافحة OAuth، تنشئ Powerduck جلستك وتوجّهك إلى وحدة التحكم. تُنشَأ منظمة شخصية تلقائياً.

## 2. إضافة المواصفة

من لوحة المعلومات، أضف مواصفة عبر مصدر مدعوم.

- **ملف** — رفع ملف OpenAPI مباشرة.
- **مستودع Git** — الإشارة إلى مستودع واختيار الفرع/مسار الملف.
- **رابط** — استيراد مواصفة من رابط.

تُرقّى مستندات OpenAPI 3.0/3.1 وSwagger القائمة، وتُحوَّل مدخلات cURL أو Postman قبل الحفظ مع معاينة.

### كيف يعمل الرفع المباشر

تُرفَع الملفات الكبيرة مباشرة إلى مخزن الكائنات، لا عبر واجهة برمجية.

1. إنشاء المستند.
2. يطلب التطبيق **رابط رفع** بنوع المحتوى والحجم.
3. يُرفَع الملف مباشرة إلى المخزن عبر الرابط المُوقَّع مسبقاً.
4. **إكمال** الرفع وتسجيل النسخة وSHA-256.

هكذا يبقى خادم الواجهة خارج مسار الحمولات الكبيرة.

## 3. اختيار العمليات المعروضة

بمجرد جاهزية المواصفة، اختر العمليات المراد جعلها عامة، قابلة للتفعيل فرادى؛ لا يتغيّر المستند الأصلي. يمكنك البدء بكل العمليات مفعَّلة وتقييد الواجهات الداخلية/الإدارية.

## 4. فتح الروابط

مع المستند النشط، تُظهر مساحة المستند العناوين العامة.

- **Documentation** — توثيق الواجهة معروض في العارض العام.
- **MCP** — نقطة MCP Streamable HTTP مُدارة.
- تُقدَّم بيانات المواصفة الأصلية أيضاً على رابط ثابت.

افتراضياً التوثيق نشط ومحمي بكلمة مرور فقط. يُضبَط توفّر MCP ومفتاح الوصول بشكل منفصل.

## 5. حماية الوصول عند الحاجة

- إضافة **كلمة مرور عرض** وتاريخ انتهاء اختياري للتوثيق.
- توليد **مفتاح وصول MCP** للنقطة.
- إيقاف المستند مؤقتاً لإنزال كليهما وقتياً.

## 6. التكرار عبر النسخ

عند تغيّر الواجهة، ارفع المحتوى الجديد كنسخة جديدة بدل استبدال القديمة. يمكن للروابط المشتركة متابعة المستند الحالي أو التثبّت على نسخة، كي لا تتغيّر تحت القرّاء.
