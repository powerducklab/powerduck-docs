# OpenAPI को कोडिंग एजेंट से जोड़ें

**डेवलपर MCP** की मदद से कोडिंग एजेंट किसी कॉन्ट्रैक्ट की जाँच कर सकता है और बैकएंड को सत्यापित कर सकता है। **API-to-MCP** API ऑपरेशन को कॉल किए जा सकने वाले टूल के रूप में उपलब्ध कराता है; यह एक अलग कार्यप्रवाह है।

1. डेस्कटॉप ऐप में **खोलें** से अपनी YAML/JSON फ़ाइल खोलें। प्रयोग करने से पहले उसकी एक अलग कॉपी सहेज लें।
2. मौजूदा स्पेसिफ़िकेशन के लिए **MCP और कोडिंग** खोलें। इसके बजाय आप डेवलपर MCP रिपॉज़िटरी की स्थानीय कॉपी में `npm ci` और `npm run build` भी चला सकते हैं।
3. अपने एजेंट में stdio MCP सर्वर कॉन्फ़िगर करें। एक्ज़ीक्यूटेबल के लिए `node` और आर्ग्युमेंट के लिए `/absolute/path/dev-mcp-server/dist/cli.mjs`, `--spec`, `/absolute/path/openapi.yaml` इस्तेमाल करें। वास्तविक पूर्ण पाथ दें; उदाहरण के प्लेसहोल्डर ज्यों के त्यों पेस्ट न करें।
4. बैकएंड बदलने से पहले एजेंट से ऑपरेशन और उसका रिस्पॉन्स स्कीमा पढ़ने को कहें। बदलाव के बाद, बैकएंड का स्थानीय `baseUrl` स्पष्ट रूप से देकर उससे `run_contract_tests` कॉल करवाएँ।
5. रिपोर्ट में दिए गए परीक्षण अभिकथनों और प्रस्तावित कोड पैच की समीक्षा करें। स्वीकृत सुधार लागू करने के बाद परीक्षण दोबारा चलाएँ।

डेवलपर MCP सर्वर के लिए Node.js 22.12.0 या उसके बाद का संस्करण चाहिए। आपका एजेंट टूल के परिणाम या कोड का संदर्भ कॉन्फ़िगर किए गए दूरस्थ मॉडल को भेज सकता है। मैन्युअल स्थानीय अनुरोधों और कॉन्ट्रैक्ट परीक्षणों के लिए मॉडल ज़रूरी नहीं है। आपकी अपनी कुंजी के उपयोग का शुल्क आपका प्रदाता लेता है; होस्ट किए गए मॉडल के क्रेडिट अलग होते हैं। स्थानीय काम के लिए Cloud सदस्यता की आवश्यकता नहीं है।
