# @powerduck/schema-editor

Schemagestützter Monaco-Editor für JSON, YAML und JavaScript. Unterstützt beliebige JSON Schemas und bietet Inline-Vorschläge, Vervollständigungsfenster, Auswahllisten für Aufzählungswerte, automatisch eingefügte Beispiele und Schemadiagnosen.

- **Paketname:** `@powerduck/schema-editor`
- **Version:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Lizenz:** MIT

## Funktionen

- **Drei Sprachen** — JSON, YAML und JavaScript (Postman-Testskripte)
- **Schemagesteuerte Vervollständigung** — Auswahllisten für Aufzählungswerte, Eigenschaftsnamen und automatisch eingefügte Beispiele aus beliebigen JSON Schemas
- **Ghost-Text** — Inline-Vorschläge für das nächste erwartete Token
- **Schemadiagnosen** — Validierungsfehler direkt im Text sowie eine Statusleiste
- **Auf Basis von Monaco** — Syntaxhervorhebung, Minimap und Befehlspalette in allen Editoren
- **Helle und dunkle Themes** — `powerduck-light` / `powerduck-dark`
- **Eigenständiges Kernmodul** — Schemaauflösung, Beispielgenerierung und Diagnosen funktionieren ohne React
