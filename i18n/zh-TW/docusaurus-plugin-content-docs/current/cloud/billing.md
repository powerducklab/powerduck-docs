# 方案與任務次數

新方案分別統計 AI 對話與程式碼審閱，不按上游 token 扣費。Free：20／5 次；Starter 每月 $19：300／30 次；Pro 每月 $39：700／90 次；Max 每月 $99：2,000／270 次。Free 在 UTC 每月月初重置，付費次數依訂閱帳期，未用次數不結轉。最終價格及稅費以結帳為準。

## 內建 AI 與使用範圍

一次對話輪次或審閱操作算一個任務，內部工具或模型批次不各自扣次。執行時預留，服務端結算；已交付結果後取消仍計一次，沒有成功結果則釋放預留。大型審閱需拆分。本機瀏覽、Git／AST 與已存結果不扣次。舊訂閱可能保留 credits 權益，以帳戶及結帳顯示為準。

## 付款與訂閱變更

只有組織擁有者和管理員可以購買或變更訂閱。升級會立即收取按比例計算的費用；降級在目前已付費週期結束後生效。取消續訂不會提前終止已付費週期內的使用權限，待生效的取消可以撤銷。

完成結帳後，請等待帳單返回頁確認訂單。若確認延遲，請重新整理現有訂單，不要重複付款。付款遭拒後可在同一結帳視窗重試。取消續訂不等於退款；退款申請請聯絡支援。
