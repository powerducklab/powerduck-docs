# Библиотеки с открытым кодом

Powerduck состоит из небольших комбинируемых npm-пакетов. Настольный клиент и облачный сервис используют одни библиотеки, поэтому те же компоненты работают локально, по сети или внутри ваших инструментов.

Каждый пакет выпускается независимо и имеет собственные инструкции по установке, справочник API и примеры. Здесь описаны их назначение и взаимосвязи.

## Слои архитектуры

```text
Powerduck / Cloud
        ↓
Встраиваемый интерфейс
        ↓
Рабочие процессы
        ↓
Основа
```

Парсер и конвертеры образуют основу. На ней строятся рабочие процессы, а выше располагается встраиваемый интерфейс. Общая база вместо повторной реализации разбора в каждом пакете обеспечивает согласованное поведение.

## Выбор подходящего пакета

- **Чтение, проверка или обновление файла OpenAPI:** начните с `openapi-parser`.
- **Преобразование cURL или коллекции Postman в OpenAPI:** используйте `x-to-openapi`.
- **Запуск сценариев или многопротокольных процессов из командной строки либо CI:** используйте `openapi-cli`.
- **Генерация клиентского кода:** используйте `openapi-codegen`.
- **Предоставление API как инструментов ИИ-агента:** используйте `openapi-mcp-server`.
- **Встраивание документации в приложение React:** используйте `oas-document`, его точку входа React и CSS.
- **Встраивание редактора:** используйте `md-editor` или `schema-editor`.

## Предоставление возможностей агентам

Пакет MCP-сервера также даёт внешним ИИ-агентам доступ к возможностям Powerduck. Спецификация, обслуживаемая через `openapi-mcp-server`, представляет операции как инструменты MCP. Тот же контракт, который используется для документации и генерации кода, агент может вызывать напрямую. Настольный клиент, Cloud и другие совместимые с MCP инструменты сохраняют единое эталонное описание.

## О примерах

Примеры кода написаны для реального API пакета и рассчитаны на выполнение в показанном виде. После обновления пакета проверяйте актуальные параметры в примечаниях к выпуску, а не копируйте фрагменты старых версий.

В боковой панели доступны установка, конфигурация и полный справочник API каждого пакета.
