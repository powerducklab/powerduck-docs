# Cloud 快速開始

這條路徑把一份規範從你的機器帶到可分享的文件頁面和 MCP 端點。

## 1. 登入

在登入頁用 **Google** 或 **GitHub** 繼續。OAuth 握手之後，Powerduck 建立自己的工作階段並把你帶入主控台。個人組織會自動建立。

## 2. 新增規範

在儀表盤用一種受支援的來源新增規範：

- **檔案上傳**——直接上傳 OpenAPI 檔案；
- **Git 儲存庫**——指向某個儲存庫並選擇分支和檔案路徑；
- **URL**——從 URL 匯入規範。

已有的 OpenAPI 3.0/3.1 和 Swagger 文件會被升級，cURL 或 Postman 輸入可在儲存前轉換以供預覽。

### 直接上傳如何工作

大檔案直接上傳到物件儲存，而不是經 API 中轉：

1. 建立一個文件；
2. 應用程式用內容類型和大小請求一個**上傳 URL**；
3. 檔案透過預簽名 URL 直接上傳到儲存；
4. 上傳被**完成**，記錄版本及其 SHA-256。

這讓 API 伺服器不處於大型載荷的資料路徑上。

## 3. 選擇暴露操作

規範就位後，選擇哪些操作公開可用。操作可單獨切換；來源文件保持不動。可從全部啟用開始，再為內部或管理介面收窄集合。

## 4. 打開連結

文件處於活動狀態後，文件工作區顯示公開位址：

- **Documentation（文件）**——公開檢視器中渲染的 API 文件；
- **MCP**——託管的 Streamable HTTP MCP 端點；
- 原始規範資料也在一個穩定 URL 上提供。

預設情況下文件啟用，僅在你新增密碼時才受保護。MCP 可用性及其存取密鑰單獨配置。

## 5. 如有需要保護存取

- 為文件新增**檢視密碼**和可選有效期；
- 為 MCP 端點產生一個 **MCP 存取密鑰**；
- 暫停文件可讓兩者暫時下線。

## 6. 用版本迭代

當 API 變化時，把新內容作為新版本上傳，而不是替換舊版本。分享連結可指向當前文件或固定到特定版本，因此引用某版本的連結從不會在讀者腳下發生變化。
