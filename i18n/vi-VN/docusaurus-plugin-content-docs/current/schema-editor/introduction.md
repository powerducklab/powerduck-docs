# @powerduck/schema-editor

Trình soạn thảo Monaco hỗ trợ lược đồ cho JSON, YAML và JavaScript. Hoạt động với mọi JSON Schema, cung cấp gợi ý nội dòng, cửa sổ tự động hoàn thành, danh sách giá trị liệt kê, tự điền ví dụ và chẩn đoán lược đồ.

- **Tên gói:** `@powerduck/schema-editor`
- **Phiên bản:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Giấy phép:** MIT

## Tính năng

- **Ba ngôn ngữ** — JSON, YAML và JavaScript (tập lệnh kiểm thử Postman)
- **Tự động hoàn thành dựa trên lược đồ** — Danh sách giá trị liệt kê, tên thuộc tính và tự điền ví dụ từ mọi JSON Schema
- **Văn bản gợi ý mờ** — Gợi ý nội dòng cho token tiếp theo được mong đợi
- **Chẩn đoán lược đồ** — Lỗi kiểm tra tính hợp lệ hiển thị ngay trong dòng, kèm thanh trạng thái
- **Dựa trên Monaco** — Tô sáng cú pháp, bản đồ thu nhỏ và bảng lệnh trong mọi trình soạn thảo
- **Giao diện sáng và tối** — `powerduck-light` / `powerduck-dark`
- **Mô-đun lõi độc lập** — Phân giải lược đồ, tạo mẫu và chẩn đoán hoạt động không cần React
