# @powerduck/schema-editor

JSON, YAML, JavaScript용 스키마 인식 Monaco 편집기입니다. 모든 JSON Schema를 기반으로 인라인 제안, 자동 완성 팝업, 열거형 드롭다운, 예제 자동 입력 및 스키마 진단을 제공합니다.

- **패키지 이름:** `@powerduck/schema-editor`
- **버전:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **라이선스:** MIT

## 기능

- **세 가지 언어** — JSON, YAML, JavaScript(Postman 테스트 스크립트)
- **스키마 기반 자동 완성** — 모든 JSON Schema에서 열거형 드롭다운, 속성 이름 및 예제 자동 입력 제공
- **인라인 제안** — 다음에 올 토큰의 제안을 편집 중인 줄에 표시
- **스키마 진단** — 검증 오류를 해당 줄과 상태 표시줄에 표시
- **Monaco 기반** — 모든 편집기에 구문 강조, 미니맵 및 명령 팔레트 제공
- **밝은 테마와 어두운 테마** — `powerduck-light` / `powerduck-dark`
- **독립형 코어** — 스키마 해석, 샘플 생성 및 진단이 React 없이 작동
