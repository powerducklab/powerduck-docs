# 既存コードから OpenAPI を生成する

デスクトップのコードから OpenAPI を生成する機能（Beta）でローカルソースのフォルダーを選び、スキャンを開始します。まず小さなサービスを対象にして、検出されたルート、パラメーター、応答を確認してください。

動的な処理や依存関係の不足により、応答 schema が不明になることがあります。手動確認はレビューの記録であり、不足する型の復元ではありません。根拠を確認して契約を編集します。任意の AI レビューでは選択したハンドラーのソースと関連情報がモデル提供者へ送信されます。

別ファイルに保存し、差分を確認してから既存仕様の置き換えを判断します。その後、[契約テスト](./contract-example.md)で実際のバックエンドを検証するか、[Agent を接続](./coding-agent.md)します。スキャン成功は契約適合の証明ではありません。

デスクトップ専用です。言語やフレームワークによって対応範囲が異なります。静的スキャンにモデルキーは不要です。不明な項目を推測で確定しないでください。
