# 요금제와 작업 횟수

새 요금제의 대화/검토 횟수: Free 10/2, Starter 월 $19 300/20, Pro 월 $39 700/60, Max 월 $99 2,000/180. Free는 UTC 월초, 유료는 구독 청구 기간에 초기화하며 이월하지 않습니다. 최종 금액과 세금은 결제 화면을 확인하세요.

## 내장 AI와 사용 범위
