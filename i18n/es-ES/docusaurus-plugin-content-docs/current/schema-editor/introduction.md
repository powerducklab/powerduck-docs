# @powerduck/schema-editor

Editor Monaco compatible con esquemas para JSON, YAML y JavaScript. Funciona con cualquier JSON Schema y ofrece sugerencias en línea, autocompletado emergente, desplegables de valores enumerados, relleno automático de ejemplos y diagnóstico del esquema.

- **Nombre del paquete:** `@powerduck/schema-editor`
- **Versión:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Licencia:** MIT

## Funciones

- **Tres lenguajes** — JSON, YAML y JavaScript (scripts de prueba de Postman)
- **Autocompletado basado en esquemas** — Desplegables de valores enumerados, nombres de propiedades y relleno automático de ejemplos a partir de cualquier JSON Schema
- **Texto fantasma** — Sugerencias en línea para el siguiente token esperado
- **Diagnóstico del esquema** — Errores de validación en línea y barra de estado
- **Basado en Monaco** — Resaltado de sintaxis, minimapa y paleta de comandos en todos los editores
- **Temas claro y oscuro** — `powerduck-light` / `powerduck-dark`
- **Núcleo independiente** — Resolución de esquemas, generación de muestras y diagnóstico sin React
