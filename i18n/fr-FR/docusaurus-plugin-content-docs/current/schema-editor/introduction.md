# @powerduck/schema-editor

Éditeur Monaco compatible avec les schémas pour JSON, YAML et JavaScript. Piloté par n’importe quel JSON Schema, il propose des suggestions en ligne, une fenêtre de complétion, des listes de valeurs énumérées, le remplissage automatique d’exemples et des diagnostics de schéma.

- **Nom du paquet:** `@powerduck/schema-editor`
- **Version:** <img src="https://img.shields.io/npm/v/@powerduck/schema-editor"/>
- **Licence:** MIT

## Fonctionnalités

- **Trois langages** — JSON, YAML et JavaScript (scripts de test Postman)
- **Complétion pilotée par le schéma** — Listes de valeurs énumérées, noms de propriétés et remplissage automatique d’exemples depuis n’importe quel JSON Schema
- **Texte fantôme** — Suggestions en ligne pour le prochain jeton attendu
- **Diagnostics de schéma** — Erreurs de validation affichées en ligne, avec une barre d’état
- **Basé sur Monaco** — Coloration syntaxique, minicarte et palette de commandes dans tous les éditeurs
- **Thèmes clair et sombre** — `powerduck-light` / `powerduck-dark`
- **Noyau autonome** — Résolution des schémas, génération d’exemples et diagnostics sans React
