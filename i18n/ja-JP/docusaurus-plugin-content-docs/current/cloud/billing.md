# 請求とライセンス

Powerduck は**2 つの異なる製品を、2 つの異なる支払いモデル**で販売します。それらを分けることが、請求を理解する最も重要な点です。

| | デスクトップクライアント | Powerduck Cloud |
|---|---|---|
| 買うもの | デスクトップアプリ | ホストサービス |
| モデル | 買い切り | 月額サブスクリプション |
| 有効期間 | 永久——ずっと所有 | 現在請求期間 |
| 成果 | **ライセンスキー**、一度だけ表示 | メンバーシップ、**キーなし** |
| オフライン動作 | はい | いいえ（ホストサービス） |

Cloud 購入がライセンスキーを生むことはなく、デスクトップ購入はサブスクリプションではありません。

## デスクトップ永久ライセンス

デスクトップクライアントは買い切り・永久所有で、更新や請求期間がありません。購入時にライセンスキーが生成されます。

- キーは自増 ID やタイムスタンプではなく、暗号論的に安全なランダムバイトから作られ、`PDC-XXXX-XXXX-…` 形。
- 元キーは**一度だけ**表示。
- データベースはキーの **SHA-256 ハッシュ**と最後 4 文字だけを持ち、元キーを逆算できません。

### ライセンス状態

ライセンスは 4 状態を経ます。

| 状態 | 意味 |
|---|---|
| `ISSUED` | 生成済みだが未有効化 |
| `ACTIVE` | 有効化済みで利用可能 |
| `SUSPENDED` | 一時的に利用不可。再有効化可 |
| `REVOKED` | 永久取消。再有効化不可 |

「永久」は計画的に期限切れしない意味で、ライセンスが停止・取消できない意味ではありません。

### 有効化と監査

有効化はキー形式を検証し、ハッシュし、ハッシュを探し、状態を確認し、トランザクション内で紐づけます。有効化エンドポイントは総当たり列挙を防ぐためレート制限されます。

各キー状態変化はライセンスイベント——作成、有効化、停止、再有効化、取消——として記録され、ライフサイクルが監査可能です。

## Cloud サブスクリプション

Cloud アクセスは、キーなしである計画の**有効サブスクリプション**に従います。

| プラン | 月額 | 年払い |
|---|---|---|
| Free | $0 | $0 |
| Pro | $19/月 | $15/月 |
| Team | $49/月 | $39/月 |

`ACTIVE` で現在期間内のサブスクリプションが、その計画の能力を付与します。短い更新猶予（3 日）が更新前後のずれをカバーし、その枠を超えるとアクセスは無料プランに解決します。Cloud 能力がデスクトップライセンスを参照することはありません。

### プランが制御するもの

計画はコードベースに計画名をハードコードして強制されません。各計画には**権益**——ブール機能と数値枠——があり、統一権益サービスで確認します。

| 能力 | Free | Pro | Team |
|---|---|---|---|
| OAS ホスティング | はい | はい | はい |
| Git ソース | いいえ | はい | はい |
| ドキュメント | はい | はい | はい |
| MCP | いいえ | はい | はい |
| カスタムドメイン | いいえ | はい | はい |
| 最大文書数 | 3 | 100 | 1,000 |
| 最大バージョン数 | 20 | 200 | 1,000 |
| 最大ファイルサイズ | 1 MiB | 10 MiB | 50 MiB |
| 最大公開操作数 | 10 | 1,000 | 10,000 |
| 最大メンバー数 | 1 | 1 | 10 |

## 支払いプロバイダー

チェックアウトは地域でルーティングされ、顧客には身近なプロバイダーが表示され、両プロバイダーが同時に出ることはありません。

- **Antom**——中国本土、香港、マカオ、台湾、東南アジア。
- **Paddle**——米国、カナダ、欧州、日本、韓国、豪州、NZ、英国。

国はクライアントのタイムゾーンか `Accept-Language` ヘッダーから推論し、外部 GeoIP データベース不要。地域を決められない場合の**フォールバックは Antom**。運用でプロバイダーを強制指定もでき、あるプロバイダー障害時に予備経路へ即切り替えできます。

支払いはブラウザの戻りページでなく、署名付きプロバイダー Webhook（Paddle と Antom で別エンドポイント）で確認されます。

## どちらを買うべきか

- 完全ローカルワークスペース、オフライン作業、永久所有が欲しい? **デスクトップライセンス**を買い切り。
- ドキュメントと MCP をオンライン公開し安定リンクを共有したい? **Cloud Pro** をサブスク（複数席は Team）。
- 多くのチームは両方使います。クライアントでローカル設計・テストし、Cloud で公開 API をホスト。
