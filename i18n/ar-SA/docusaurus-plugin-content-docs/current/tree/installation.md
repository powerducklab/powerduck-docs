# التثبيت

```bash npm2yarn2pnpm
npm install @powerduck/tree
```

## الاعتماديات النظيرة

```bash
npm install react react-dom react-icons
```

## استيراد CSS

```tsx
import "@powerduck/tree/react/index.css";
```

## نقاط الدخول

| مسار الاستيراد | الوصف |
|--------|-------------|
| `@powerduck/tree` | الأنواع الأساسية والأدوات المساعدة وجميع المهايئات |
| `@powerduck/tree/react` | مكوّن Tree لـ React والخطافات |
| `@powerduck/tree/adapters` | مهايئات OpenAPI وJSON Schema والتوثيق |
| `@powerduck/tree/core` | الأنواع الأساسية والأدوات المساعدة فقط |
