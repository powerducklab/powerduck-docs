# 데스크톱 클라이언트

데스크톱을 포함한 Powerduck은 Google OAuth 또는 GitHub 로그인이 필요합니다. 파일은 로컬에 저장됩니다. AI 분석은 선택한 컨텍스트를 플랫폼이 관리하는 공급자에게 전송합니다. 사용자 지정 모델 주소와 API 키는 지원하지 않습니다.

항상 당신이 통제합니다. 어시스턴트가 제안하고 당신이 승인합니다.

## 워크스페이스에서의 하루

다음은 바로 클라이언트가 중심에 두는 순간들입니다.

- **스펙을 열고 전체를 파악하기.** 어시스턴트가 현재 문서를 읽고 할 수 있는 일을 즉시 제안합니다——채울 빈칸, 완성할 문서, 테스트할 플로우.
- **API 구축하기.** 리소스를 설명하면 어시스턴트가 작업을 제안합니다. 같은 작업을 계속 refine——매개변수 추가, 응답 조이기, 상태 코드 조정——하면 문서 전체로 흐트러지지 않고 그 API에 머뭅니다.
- **테스트 데이터 준비하기.** 스키마에서 실제 같은 샘플 데이터를 생성해 요청과 시나리오에 구체적 값을 줍니다.
- **단일 요청 또는 완전한 시나리오 실행하기.** 한 번의 호출을 디버깅하거나 여러 작업을 엔드투엔드 플로우로 연결하고 무엇이 통과하고 실패했는지 공유 가능한 보고서를 받습니다.
- **백엔드 준비 전에 계속 진행하기.** 로컬 모크를 시작해 실제 서비스 개발 중에도 계약에 따라 응답합니다.
- **API를 코딩 에이전트에 전달하기.** 스펙을 MCP 서버로 바꿔 AI 도구가 올바른 매개변수로 올바른 작업을 발견하고 호출하게 합니다.
- **API 뒤의 데이터베이스 내다보기.** 스펙에서 테이블, 관계, SQL을 도출하고 실제 데이터베이스와 대조해 일어나려는 변경을 파악합니다.
- **대화를 떠나지 않고 설정 변경하기.** 테마나 언어 전환, 프록시 설정, 환경 변수 관리를 말로 요청하는 것만으로 수행합니다.

## 어시스턴트와 협업하는 방식

자연어로 의도를 설명하면 어시스턴트가 적절한 능력을 선택하고 결정론적 엔진이 검증하며 당신이 카드로 승인합니다. 모델이 스스로 문서를 편집하지 않습니다.

- 스펙 변경은 세밀한 작업을 담은 **패치 카드**로 도착합니다. 기존 작업 편집 시 요청한 필드만 변경됩니다.
- 읽기 전용 작업——작업 나열, 스키마 가져오기, 쿼리 실행——은 어시스턴트가 답변의 근거로 삼는 사실을 반환합니다.
- 쓰기 작업은 실행 전 확인을 요청합니다.

## Powerduck · Free / Pro / Max

Free는 매일 300,000 credits를 제공하며 UTC 00:00에 초기화됩니다. Pro는 월 $39에 7일마다 18,000,000 credits, Max는 월 $99에 7일마다 60,000,000 credits를 제공합니다. 최초 구독 시작을 기준으로 초기화하며 월 결제와 별개입니다. 이월되지 않습니다. 데스크톱과 AI Chat은 개인 계정 요금제를 공유하며 영구 라이선스와 활성화 키는 판매하지 않습니다.
