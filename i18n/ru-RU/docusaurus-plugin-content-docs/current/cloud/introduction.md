# Powerduck Cloud

Powerduck Cloud позволяет **делиться** содержимым файла OpenAPI. Добавьте спецификацию, выберите доступные операции и передайте пользователям постоянные ссылки на документацию и управляемый сервер MCP — размещать и запускать эти сервисы самостоятельно не нужно.

Это тот же подход, что и в настольном клиенте: работа на основе контракта API с помощью ИИ, но в онлайн-среде для команд и пользователей API. План Free включает размещение документации и MCP в пределах своих лимитов; платные планы увеличивают лимиты и добавляют источники Git и собственные домены. Сама прикладная API продолжает работать на вашем сервере.

## Порядок работы

1. **Добавьте спецификацию**: загрузите файл, укажите репозиторий Git или вставьте URL. Начать можно прямо на сайте, а войти в аккаунт — когда будете готовы. Загружать файл повторно не потребуется.
2. **Выберите доступные операции.** Включайте и отключайте их по отдельности; исходный файл при этом не изменяется.
3. **Сразу откройте ссылку на документацию.** Отображение документации API включено по умолчанию. Управляемый эндпоинт MCP включается отдельным переключателем и остаётся выключенным, пока вы не решите предоставить агентам доступ к инструментам.
4. **Настройте доступ.** Задайте пароль и срок доступа к документации, а для агентов — отдельный ключ доступа MCP.
5. **Опубликуйте и поделитесь.** Опубликуйте готовый артефакт текущей версии, чтобы ссылки заработали; расширенные настройки доступны в один клик.
6. **Поддерживайте актуальность.** Каждое изменение создаёт новую версию, которую можно сравнить с другими или восстановить. Источники Git могут синхронизироваться при обновлении.
7. **Управляйте жизненным циклом.** Приостанавливайте, возобновляйте или архивируйте документы; просматривайте их состояние, версии и источник.

## Возможности

- **Постоянные ссылки на документацию**, которые продолжают работать после публикации новых версий;
- **Управляемый эндпоинт MCP**, позволяющий ИИ-агентам других пользователей находить и вызывать выбранные вами операции;
- **Настройка доступа к каждой операции**, чтобы внутренние или незавершённые эндпоинты не попадали в публичный интерфейс;
- **Контроль доступа** с паролями просмотра, сроками действия и ключами MCP;
- **История версий** со сравнением и восстановлением без перезаписи оригинала;
- **Синхронизация Git**, превращающая обновление репозитория в новую размещённую версию;
- **Собственные домены**, в том числе с вложенными путями, для оформления под вашим брендом.

### Один документ — несколько версий

Каждое редактирование создаёт новую версию, а не перезаписывает оригинал. Можно сравнивать версии, возвращаться к предыдущим и заново публиковать документацию и MCP из известного состояния. Документация и MCP всегда связаны с конкретным документом и конкретной версией, а не с неопределённой «последней» версией.

### Почему ссылка может не открываться

Ссылка на документацию или MCP работает при выполнении трёх условий. Рабочая область документа показывает их все и выделяет первое невыполненное:

1. Документ **активен**: приостановка одновременно отключает документацию и MCP;
2. Нужный сервис **включён**: у документации и MCP отдельные переключатели; документация включена по умолчанию, MCP выключен;
3. Актуальный артефакт **опубликован**: он собирается автоматически после добавления версии или изменения доступных операций, поэтому обычно вмешательство не требуется; при необходимости можно запустить публикацию вручную.

Помимо этих условий применяются проверки доступа: пароль просмотра, срок действия или ключ MCP.

## Вход и владение ресурсами

Войдите через **Google** или **GitHub**. После обмена OAuth Powerduck создаёт собственную сессию с защищённым cookie HttpOnly; токен провайдера не используется как ваша постоянная идентификация. Все ресурсы принадлежат **организации**. Личная организация создаётся автоматически; позже команда сможет использовать общую организацию без перестройки системы.

## Консоль

- **Панель управления**: добавление спецификаций, недавние документы, быстрые ссылки и действия запуска и остановки;
- **Проекты**: организация документов;
- **Рабочая область документа**: состояние, документация, MCP, доступные операции, версии, источник и домены в отдельных подписанных разделах;
- **Оплата**: состояние подписки и заказы, представленные отдельно;
- **Hub**: публикация и поиск общедоступной документации и серверов MCP;
- **Настройки** и **Активность**: профиль, предпочтения и журнал аудита.

Читатели публичной документации используют отдельный просмотрщик; аккаунт Powerduck им не нужен. Если установлен пароль просмотра, его потребуется ввести. Пароль документа и вход в аккаунт — разные требования.

## Cloud и настольный клиент

| | Настольный клиент | Cloud |
|---|---|---|
| Где работает | На вашем компьютере | В облаке |
| Модель оплаты | Бессрочная лицензия с разовой оплатой | Бесплатный план и платные подписки |
| Что предоставляется | Лицензионный ключ, показываемый один раз | Возможности плана без лицензионного ключа |
| Основное назначение | Полноценная локальная и автономная работа | Совместный доступ и публикация в интернете |

Продукты дополняют друг друга. У Cloud есть план Free; платные подписки Cloud и настольные лицензии приобретаются отдельно. См. раздел [Оплата](./billing.md).
