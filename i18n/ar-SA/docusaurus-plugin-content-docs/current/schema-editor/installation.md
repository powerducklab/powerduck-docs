# التثبيت

```bash npm2yarn2pnpm
npm install @powerduck/schema-editor
```

## الاعتماديات النظيرة

```bash
npm install react react-dom monaco-editor @monaco-editor/react
```

## نقاط الدخول

| مسار الاستيراد | الوصف |
|--------|-------------|
| `@powerduck/schema-editor` | واجهة API الأساسية: حلّ مراجع المخططات والتشخيص وإنشاء الأمثلة |
| `@powerduck/schema-editor/react` | مكوّن React‏ `<SchemaEditor />` |
| `@powerduck/schema-editor/core` | نواة متوافقة مع المتصفح دون React |
