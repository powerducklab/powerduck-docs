# Cài đặt

```bash npm2yarn2pnpm
npm install @powerduck/schema-editor
```

## Phụ thuộc ngang hàng

```bash
npm install react react-dom monaco-editor @monaco-editor/react
```

## Điểm vào

| Đường dẫn nhập | Mô tả |
|--------|-------------|
| `@powerduck/schema-editor` | API cốt lõi: phân giải lược đồ, chẩn đoán và tạo dữ liệu mẫu |
| `@powerduck/schema-editor/react` | Thành phần React `<SchemaEditor />` |
| `@powerduck/schema-editor/core` | Phần lõi dùng được trong trình duyệt mà không cần React |
