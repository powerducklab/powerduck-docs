# Powerduck Cloud

Powerduck Cloud는 OpenAPI 파일을 **공유할 수 있는** 것으로 바꿉니다. 스펙을 추가하고 노출할 것을 선택한 뒤 렌더링 문서와 관리형 MCP 서버의 안정 링크를 다른 사람에게 전달합니다. 직접 호스팅하거나 무언가를 실행할 필요가 없습니다.

데스크톱 클라이언트와 같은 계약 우선, AI 지원 워크플로를 팀과 소비자를 위해 온라인으로 옮긴 것입니다.

## 여정

1. **스펙 추가**——파일 업로드, Git 저장소, URL 중 하나. 웹사이트에서 흐름을 시작하고 준비되면 로그인할 수도 있어 두 번 업로드할 필요가 없습니다.
2. **노출할 것 선택.** 작업을 개별로 켜고 끕니다. 원본 파일은 바뀌지 않습니다.
3. **문서 링크 바로 열기**——렌더링 API 문서는 기본 켜짐. 관리형 MCP 엔드포인트는 에이전트에 도구를 노출하기로 할 때까지 꺼진 채, 스위치 하나입니다.
4. **접근 통제.** 문서 보기 비밀번호와 유효 기간, 에이전트용 독립 MCP 접근 키 추가.
5. **게시하고 공유.** 현재 버전의 준비된 결과물을 게시하면 링크가 해결되고 고급 제어는 한 번의 클릭으로 닿습니다.
6. **최신 유지.** 변경마다 새 버전을 만들어 비교하거나 롤백하고 Git 소스는 갱신 시 동기화.
7. **라이프사이클 관리.** 문서 일시정지, 재개, 보관하고 상태, 버전, 소스를 한눈에 확인.

## 얻는 것

- **안정 문서 링크**——새 버전 게시 후에도 읽힘.
- **관리형 MCP 엔드포인트**——다른 사람 AI 에이전트가 선택한 작업을 발견하고 호출.
- **작업별 노출**——내부나 미완성 인터페이스를 공개 면에서 제외.
- **접근 통제**——보기 비밀번호, 유효 기간, MCP 접근 키.
- **버전 이력**——비교와 롤백. 원본은 덮어쓰이지 않음.
- **Git 동기화**——저장소 갱신을 새 호스트 버전으로 반영.
- **사용자 지정 도메인**——하위 경로 구성을 포함한 브랜드 경험.

### 하나의 문서, 여러 버전

편집마다 덮어쓰기 대신 새 버전을 만들어 버전 비교, 롤백, 특정 상태에 대한 문서/MCP 재생성을 할 수 있습니다. 문서와 MCP는 항상 특정 문서와 버전에 묶이고 모호한 "최신"을 가리키지 않습니다.

### 왜 링크가 안 열릴 수 있는가

세 가지가 갖춰지면 문서나 MCP 링크가 해결되고, 문서 워크스페이스가 각 항목을 보여주며 첫 미충족 요건을 강조합니다.

1. 문서가 **활성** 상태——일시정지하면 문서와 MCP가 함께 내려감.
2. 공유할 모드가 **활성**——문서와 MCP에 각 스위치(문서 기본 켜짐, MCP 기본 꺼짐).
3. 현재 결과물이 **게시됨**——버전 추가나 노출 작업 변경 후 자동 구축돼 보통 조작 불필요. 수동 게시는 대비책으로 제공.

접근 확인——보기 비밀번호, 유효 기간, MCP 접근 키——은 이 세 가지 위에서 동작합니다.

## 로그인과 귀속

**Google** 또는 **GitHub**로 로그인합니다. OAuth 핸드셰이크 후 Powerduck은 안전한 HttpOnly 쿠키로 자체 세션을 발급하고 제공업체 토큰이 장기 신분으로 쓰이지 않습니다. 모든 것은 **조직**에 귀속되고 개인 조직이 자동 생성돼 나중에 팀이 재설계 없이 공유할 수 있습니다.

## 콘솔

- **Dashboard**——스펙 추가, 최근 문서를 빠른 링크와 시작/정지 동작으로 확인.
- **Projects**——문서 정리.
- **문서 워크스페이스**——상태, 문서, MCP, 노출 작업, 버전, 소스, 도메인을 명확한 탭으로.
- **Billing**——구독 상태와 주문을 분리해 유지.
- **Hub**——공개 문서와 MCP 서버 게시 및 탐색.
- **Settings**와 **Activity**——프로필, 기본 설정, 감사 로그.

공개 독자는 전용 문서 뷰어를 쓰고 문서가 비밀번호를 요구하지 않으면 계정이 필요 없습니다.

## Cloud와 데스크톱 클라이언트

| | 데스크톱 클라이언트 | Cloud |
|---|---|---|
| 실행 | 당신 머신 | 호스팅 |
| 모델 | 한 번 구매 영구 라이선스 | 월간 구독 |
| 결과 | 라이선스 키(한 번만 표시) | 멤버십, 키 없음 |
| 적합 상황 | 로컬, 오프라인, 완전 워크스페이스 | 온라인 공유와 게시 |

둘은 보완하고 따로 판매됩니다. [청구](./billing)를 보세요.
