# Instalasi

```bash npm2yarn2pnpm
npm install @powerduck/tree
```

## Dependensi peer

```bash
npm install react react-dom react-icons
```

## Impor CSS

```tsx
import "@powerduck/tree/react/index.css";
```

## Titik masuk

| Impor | Deskripsi |
|--------|-------------|
| `@powerduck/tree` | Tipe inti, utilitas, dan semua adaptor |
| `@powerduck/tree/react` | Komponen Tree React dan hook |
| `@powerduck/tree/adapters` | Adaptor OpenAPI, JSON Schema, dan dokumentasi |
| `@powerduck/tree/core` | Hanya tipe inti dan utilitas |
