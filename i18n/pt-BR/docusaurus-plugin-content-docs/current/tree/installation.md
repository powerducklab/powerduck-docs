# Instalação

```bash npm2yarn2pnpm
npm install @powerduck/tree
```

## Dependências pares

```bash
npm install react react-dom react-icons
```

## Importação de CSS

```tsx
import "@powerduck/tree/react/index.css";
```

## Pontos de entrada

| Importação | Descrição |
|--------|-------------|
| `@powerduck/tree` | Tipos principais, utilitários e todos os adaptadores |
| `@powerduck/tree/react` | Componente Tree para React e hooks |
| `@powerduck/tree/adapters` | Adaptadores de OpenAPI, JSON Schema e documentação |
| `@powerduck/tree/core` | Apenas tipos principais e utilitários |
