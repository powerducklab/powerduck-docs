# @powerduck/tree

API नेविगेशन, स्कीमा ब्राउज़िंग और दस्तावेज़ों के लिए विस्तार योग्य ट्री कंपोनेंट। सामान्य कोर पर आधारित, जिसमें OpenAPI, JSON Schema और कस्टम डेटा स्रोतों के अडैप्टर हैं।

- **पैकेज का नाम:** `@powerduck/tree`
- **संस्करण:** <img src="https://img.shields.io/npm/v/@powerduck/tree"/>
- **लाइसेंस:** MIT

## सुविधाएँ

- **सामान्य कोर** — `TreeNode<TMetadata>` किसी भी डेटा स्रोत के साथ काम करता है
- **OpenAPI अडैप्टर** — OAS 3.2 के नेस्टेड टैग, `x-tagGroups`, `x-order`, `x-displayName` और `x-internal` वाला टैग-आधारित नेविगेशन
- **JSON Schema अडैप्टर** — `jsonPath` मेटाडेटा के साथ नेस्टेड प्रॉपर्टी, ऐरे और कॉम्बिनेटर को गहराई तक खोलना
- **दस्तावेज़ अडैप्टर** — ऑपरेशन की संख्या के बैज वाला Stripe जैसा दस्तावेज़ ट्री
- **React कंपोनेंट** — खोज, खोलना और समेटना, कीबोर्ड नेविगेशन, मेथड बैज और कस्टम रेंडर props
- **ड्रैग और ड्रॉप** — एक ही पैरेंट के भीतर क्रम बदलना और दूसरे स्तर के फ़ोल्डर में ले जाना
- **संदर्भ मेन्यू** — राइट-क्लिक या अधिक विकल्प बटन से हर नोड की कार्रवाइयाँ
- **प्रोग्राम के ज़रिए स्थान ढूँढना** — `locateNode(predicate)` नोड ढूँढता है, उसके पूर्वजों को खोलता है, उसे चुनता है और दृश्य क्षेत्र में लाता है
- **JSON Patch एकीकरण** — `onPatch` कॉलबैक RFC 6902 ऑपरेशन भेजता है
- **CSS वेरिएबल से थीम** — Powerduck के `tokens.css` तथा हल्के और गहरे मोड के साथ संगत
