# 代码审阅

代码审查需要使用[桌面客户端](https://www.powerduck.com/download.html)。浏览器页面提供下载入口；本地项目选择、Git 对比和代码审查不在浏览器中运行。

选择代码目录后先查看项目结构，点击文件阅读完整源码。支持仅源码、完整对比、仅改动三种视图；通过增删行、行内字符高亮、改动导航和搜索定位实际修改，同时保留上下文。

## 对比范围与轮次历史

本轮改动比较已保存的轮次起点与磁盘文件。首次打开目录会建立起点，不会把已有内容自动当成新增工作；全部未提交改动则与 Git HEAD 对比。主动开始新一轮，并通过历史选项查看已捕获的旧轮次差异。历史保存在本地，不是 Git 备份；编辑器中的修改需保存到磁盘后才能被发现。

## 项目结构与关联代码

本地 Git 差异与解析器识别改动块及可解析的定义、调用方和导入关系。将鼠标移到受支持的符号上可查看定义，在改动旁展开关联代码。项目结构可筛选引用较多的文件、临时命名候选、内容相同的文件及未解析到入向引用的文件。这些只是静态信号，可能遗漏动态加载、框架入口和外部使用方；无引用不代表可删除，文本相同也不证明行为可互换。

## AI 行内审阅

只有主动发起审阅才触发 AI。系统将当前差异与有界的关联上下文分批送审，而非逐个发送完整文件；结果出现在对应代码位置，包含优先级、证据和核查建议。相同内容可复用匹配的缓存结果。可以确认需处理、标记误报，或选入 Agent 任务。AI 可能漏报或误报，不能证明代码正确，也不能证明测试已运行。

## Agent 任务包

勾选多条疑点后打开 Agent 任务包，可预览、复制或下载包含代码上下文和版本锚点的 Markdown。接收任务的 Agent 应独立判断疑点；是否允许修改会在任务包中明确注明。粘贴其 JSON 报告后仍需人工复核，声称已修复不等于测试通过。导出任务包不会自动启动或联系其他 Agent。

## 运行检查

主动运行检查，执行识别到的项目命令，并查看命令、退出码与原始输出；缺少脚本表示尚未验证，不能算通过。项目脚本会在你的计算机执行代码，请仅对可信项目使用。文件读取、静态分析和 AI 审阅本身不构成执行证据；标记已读只记录阅读进度。

## 内置 AI 与使用范围

使用 Google 或 GitHub 登录。产品仅提供内置模型，不提供模型选择、自带密钥或自定义端点。只有请求 AI 工作时才向托管模型服务发送所选代码上下文。本地扫描排除常见依赖、构建和凭据路径，但不能保证源码中没有秘密信息，请核对分享范围。
